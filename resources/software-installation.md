# Software Installation Guide

Install these free tools before the course begins. Ask the instructor for help if your computer shows a different screen.

## 1. Visual Studio Code

1. Open https://code.visualstudio.com/
2. Download the version for your operating system.
3. Run the installer.
4. Follow the installation steps.
5. Open Visual Studio Code.

## 2. Google Chrome

1. Open https://www.google.com/chrome/
2. Download and install Chrome.
3. Open Chrome once the installation finishes.

## 3. Live Server extension

1. Open Visual Studio Code.
2. Select the Extensions icon.
3. Search for **Live Server**.
4. Check the publisher and install the commonly used Live Server extension by Ritwick Dey.
5. Open an HTML file.
6. Use **Go Live** in the status bar to start a local preview.

If the extension is unavailable, students can open the HTML file directly in Chrome for basic practice.

## 4. Git

1. Open https://git-scm.com/downloads
2. Download Git for your operating system.
3. Install it using the normal installer options.
4. Open a terminal or command prompt.
5. Run:

```bash
git --version
```

A version number means Git is installed.

## 5. GitHub account

1. Open https://github.com/
2. Select Sign up.
3. Follow the account creation steps.
4. Use an email address you can access.
5. Keep your password private. Never share it with classmates or publish it in a code file.

## Check before class

- [ ] VS Code opens.
- [ ] Chrome opens.
- [ ] Live Server is installed or an HTML file opens in Chrome.
- [ ] Git responds to `git --version`.
- [ ] You can sign in to GitHub.

## Computer recommendation

A laptop or desktop computer is strongly recommended. Students should have permission to install software and should keep their course files backed up.
