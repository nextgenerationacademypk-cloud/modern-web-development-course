# Recommended Student Reference Book

## Main recommendation

**Learning Web Design: A Beginner's Guide to HTML, CSS, JavaScript, and Web Images, 6th Edition**

- **Author:** Jennifer Niederst Robbins
- **Contributions to the JavaScript section:** Aaron Gustafson
- **Publisher:** O'Reilly Media
- **Publication:** 2025
- **Print ISBN:** 978-1-098-13768-7
- **Official book website:** https://learningwebdesign.com/
- **Publisher book page:** https://www.oreilly.com/library/view/learning-web-design/9781098137670/

This is the recommended supporting reference for the academy's *Modern Web Development — Complete Beginner to Practical Developer* course. It starts with web foundations and progresses through HTML, CSS, responsive layouts, JavaScript, and the DOM. It is written for beginners and includes hands-on exercises and chapter review questions.

**Important:** This book is a reference, not a replacement for the academy's 40 daily lesson packages. The academy lessons define what students must learn and what will be assessed. The book is broader and longer than this 8-week, 80-hour course, so students should read only the selected chapters below.

## Suggested reading plan

| Course week | Academy topic | Suggested book reading |
|---|---|---|
| Week 1 | Web foundations and first webpage | Chapters 1–3: teams and tools, how the web works, and important web concepts |
| Week 2 | HTML5 | Chapters 4–9: creating pages, text, links, images, tables, and forms |
| Week 3 | CSS foundations | Chapters 11–16: CSS introduction, text, colour, selectors, box model, and positioning |
| Week 4 | Responsive web design | Chapters 17–19: Flexbox, Grid, and responsive web design |
| Week 5 | JavaScript foundations | Chapters 22–23: JavaScript basics, functions, conditionals, arrays, and loops |
| Week 6 | DOM and events | Chapter 24: working with the DOM and events |
| Week 7 | Git, GitHub, GitHub Pages, and introductory Tailwind | Use the academy's Week 7 lesson materials and the official documentation linked in [Useful Learning Links](useful-links.md). The book is not the course reference for Git or GitHub. |
| Week 8 | Final project | Review the relevant HTML, CSS, responsive design, JavaScript, and DOM chapters while building the project |

## Optional reading

These topics are useful but are not required for the course assessment:

- Chapter 10 — Embedded media
- Chapter 20 — Transitions, transforms, and animation
- Chapter 21 — More CSS techniques
- Chapter 25 — Next-level JavaScript
- Chapters 26–28 — Web image production and SVG

Students should focus on the core weekly reading first. Do not let optional chapters delay practical assignments or the final project.

## How students should use the book

1. Read the assigned section before or after the matching classroom lesson.
2. Type and test examples yourself; do not only read the code.
3. Try the chapter exercises and "Test Yourself" questions.
4. If a book example differs from the instructor's demonstration, ask the instructor before changing the course project.
5. Keep practising with the academy's daily exercises, homework, and projects.

## Access and copyright

The book is a commercial publication. Students are **not required to purchase it** to complete the course. The academy's lesson materials and the free official online documentation are the required learning resources. Students who use the book should obtain it through a legitimate library, bookstore, publisher, or authorised digital-book provider. Do not upload or distribute unauthorised scans or copies.
