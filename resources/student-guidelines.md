# Student Guidelines

Welcome to the course. You do not need to know programming before your first class. You do need patience, regular practice, and a willingness to try.

## In every class

- Arrive on time.
- Bring your laptop and charger.
- Open the correct course folder.
- Type the code yourself instead of only watching.
- Save your work regularly.
- Ask questions when something is unclear.
- Test your page in the browser.
- Keep your files organised.

## Good coding habits

- Use clear file and folder names.
- Keep HTML, CSS, and JavaScript organised.
- Indent code consistently.
- Use meaningful names for variables and classes.
- Read error messages carefully.
- Make one change at a time when debugging.
- Do not copy code you cannot explain.

## Homework

Complete the assigned task before the next class. If you are stuck, write down what you tried and what happened. Bring that information to the instructor.

## Online safety

- Never share your passwords.
- Never publish private information in a website.
- Do not place secret keys or passwords in GitHub repositories.
- Use images and other materials you have permission to use.

## Learning mindset

Mistakes are a normal part of programming. Read, test, fix, and try again. Progress comes from writing code regularly.
