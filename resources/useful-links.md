Use these trusted documentation and practice websites during the course.

| Resource | Best use | Link |
|---|---|---|
| MDN Web Docs | Reliable HTML, CSS, and JavaScript reference | https://developer.mozilla.org/ |
| W3Schools | Beginner explanations and quick examples | https://www.w3schools.com/ |
| freeCodeCamp | Guided coding practice | https://www.freecodecamp.org/ |

| Git | Git downloads and documentation | https://git-scm.com/doc |
| GitHub Docs | Repositories and GitHub Pages | https://docs.github.com/ |
| Tailwind CSS | Current installation and utility documentation | https://tailwindcss.com/docs |

## How to use documentation

1. Search for the exact topic you are learning.
2. Read the short explanation.
3. Look at a small example.
4. Type the example yourself.
5. Change one thing and observe the result.
6. Ask the instructor if the result is confusing.

Use current official documentation for Tailwind installation. Do not follow an old setup tutorial without checking its version.
