# Day 23 — Conditions

## Lesson goal
Use conditions to make a program choose between different actions based on a value or comparison.

## Learning outcomes
- Explain why programs need decisions.
- Write `if`, `else if`, and `else` statements.
- Use comparison operators.
- Combine simple conditions with `&&` and `||`.
- Trace a condition and predict which block runs.

## Class plan (120 minutes)
20 min explanation · 4 min theory review · 30 min instructor demo · 62 min student practice · 4 min review.

## Learning resources
- **Read:** [MDN: Making decisions in your code — conditionals](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/Conditionals)
- **Read:** [MDN: Comparison operators](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Expressions_and_operators#comparison_operators)
- **Watch (optional):** [JavaScript for Beginners — Programming with Mosh](https://www.youtube.com/watch?v=W6NZfCO5SIk), selected section on conditional statements.

## Practical result
A simple program that checks a number and reports whether it is positive, negative, or zero, plus a sample marks result.

## Homework
Write a program that checks a fictional test score and prints a suitable result message. Use clear boundaries and test values around the pass mark.

## Quick check
1. What does an `if` statement do?
2. When does `else` run?
3. Why is the order of `if` and `else if` important?
4. What does `&&` mean?
5. What does `||` mean?

## Completion check
Student can write and trace a simple decision with at least two possible outcomes.
