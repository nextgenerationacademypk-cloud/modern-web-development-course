# Day 23 Homework — Score Checker

## Task
Write a JavaScript program that checks a fictional test score and prints a result.

## Requirements
- Store a score in a variable.
- Use `if`, `else if`, and `else`.
- Use clear result messages.
- Test at least four values, including the exact pass boundary.
- Add comments explaining the score ranges.

## Suggested rules
- 80 or above: Excellent.
- 60 to 79: Pass.
- Below 60: Keep practising.

## Submit
Submit your HTML and JavaScript files and list the test values with the message each one produced.

## Optional challenge
Add a check that reports an invalid score below 0 or above 100 before checking the result.
