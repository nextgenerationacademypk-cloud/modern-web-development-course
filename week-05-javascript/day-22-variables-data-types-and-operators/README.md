# Day 22 — Variables, Data Types and Operators

## Lesson goal
Store information in variables, identify simple JavaScript data types, and use operators to calculate and compare values.

## Learning outcomes
- Declare variables with `const` and `let`.
- Explain the difference between changing and non-changing variable bindings.
- Recognise strings, numbers, and booleans.
- Use arithmetic operators and comparison operators.
- Display values with `console.log()`.

## Class plan (120 minutes)
20 min explanation · 4 min theory review · 30 min instructor demo · 62 min student practice · 4 min review.

## Learning resources
- **Read:** [MDN: Variables](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/Variables)
- **Read:** [MDN: Numbers and strings](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/Numbers_and_strings)
- **Read:** [MDN: Basic math in JavaScript](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/Math)
- **Watch (optional):** [JavaScript for Beginners — Programming with Mosh](https://www.youtube.com/watch?v=W6NZfCO5SIk), selected sections on variables and operators.

## Practical result
A small marks and fee calculator that stores values and prints calculated results.

## Homework
Create a simple shopping total calculator using item prices and quantity. Use variables, arithmetic operators, and clear output messages.

## Quick check
1. When should you use `const`?
2. When is `let` useful?
3. Give one example of a string, number, and boolean.
4. What does `%` calculate?
5. What is the difference between `=` and `===`?

## Completion check
Student declares variables, performs arithmetic, compares two values, and explains the output.
