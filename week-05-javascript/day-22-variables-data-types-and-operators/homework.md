# Day 22 Homework — Shopping Total Calculator

## Task
Create a small program that calculates the total cost of a fictional shopping list.

## Requirements
- Store at least two item prices in number variables.
- Store item quantities in number variables.
- Calculate a total using arithmetic operators.
- Use at least one string and one boolean.
- Use `console.log()` to show clear results.
- Use meaningful variable names.

## Submit
Submit `index.html` and `script.js`, plus a short explanation of the variables and operators you used.

## Optional challenge
Apply a 10% discount when the total is greater than a sample amount you choose.

## Reminder
Do not use real private financial information. Use fictional prices and quantities.
