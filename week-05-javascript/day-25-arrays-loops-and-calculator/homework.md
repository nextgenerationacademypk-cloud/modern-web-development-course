# Day 25 Homework — Finish the Guided Calculator

## Task
Complete and test the console-based calculator started in class.

## Requirements
- Four functions: add, subtract, multiply, and divide.
- Use two number variables as the calculator inputs.
- Print all four results.
- Handle division by zero with a clear message.
- Include an array of at least three items.
- Use a basic `for` loop to print each array item.

## Test your program
Use at least these test cases:
- 20 and 5.
- 9 and 3.
- 12 and 0 for division-by-zero handling.

## Submit
Submit `index.html` and `script.js`. Add a short note explaining how your loop works and what happens when the divisor is zero.

## Optional challenge
Add a function that returns the larger of two numbers.

## Important
This is a console-based exercise. Do not add buttons, input fields, or DOM code; those are part of Week 6.
