# Day 25 — Arrays, Loops and Guided Calculator

## Lesson goal
Store multiple values in an array, use a basic loop to visit each item, and combine Week 5 skills in a guided calculator program.

## Learning outcomes
- Create an array of values.
- Read array items using their index.
- Explain that array indexes begin at 0.
- Use a basic `for` loop to repeat an action.
- Use functions and conditions in a small calculator.
- Handle division by zero with a clear message.

## Class plan (120 minutes)
20 min explanation · 4 min theory review · 30 min instructor demo · 62 min student practice · 4 min review.

## Learning resources
- **Read:** [MDN: Arrays](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/Arrays)
- **Read:** [MDN: Looping code](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/Loops)
- **Watch (optional):** [JavaScript for Beginners — Programming with Mosh](https://www.youtube.com/watch?v=W6NZfCO5SIk), selected sections on arrays and loops.

## Practical result
A console-based calculator that uses functions to add, subtract, multiply, and divide two sample numbers. It prints a safe message if the divisor is zero.

## Homework
Finish the guided calculator, test all four operations, and explain how the loop visits each item in a small array.

## Quick check
1. What is an array?
2. What is the index of the first array item?
3. What does `array.length` tell us?
4. What does a `for` loop repeat?
5. Why should a calculator check for division by zero?

## Completion check
Student creates an array, uses a loop to print each item, and explains the calculator's functions and zero-division check.

## Scope note
This is a guided, console-based logic exercise. DOM interaction, buttons, input fields, and event listeners are taught in Week 6.
