# Day 25 Practical Exercises — Arrays, Loops and Calculator

## Exercise 1 — Create an array (8 min)
Create an array containing three course subjects. Print the full array.

## Exercise 2 — Read by index (8 min)
Print the first, second, and third items. Remember that the first index is 0.

## Exercise 3 — Use length (8 min)
Print the number of items using the array's `length` property.

## Exercise 4 — Write a for loop (12 min)
Use a basic `for` loop to print every item. Trace the index values before running the code.

## Exercise 5 — Calculator functions (12 min)
Create functions for addition, subtraction, multiplication, and division. Print each result.

## Required guided project (20 min)
Complete a console calculator using two number variables. The division function must return a clear message if the second number is zero.

## Test checklist
- [ ] Array contains at least three values.
- [ ] First item is accessed with index 0.
- [ ] Array length is printed.
- [ ] Loop visits each item exactly once.
- [ ] Calculator has four operation functions.
- [ ] Normal calculations are correct.
- [ ] Division by zero is handled clearly.

## Optional challenge
Create an array of sample marks and use a loop to print each mark. Do not add DOM buttons or input fields yet.

## Troubleshooting
Check the starting index, loop condition, and index increment. If the loop never stops, stop the page and inspect the loop condition before running it again.
