# Day 21 — Introduction to JavaScript

## Lesson goal
Understand what JavaScript does on a webpage, connect an external JavaScript file, and use the browser console to see program output.

## Learning outcomes
- Explain the roles of HTML, CSS, and JavaScript.
- Describe what a script is at a beginner level.
- Link an external JavaScript file with the `defer` attribute.
- Use `console.log()` and the browser developer console.
- Find and fix a simple filename or syntax error.

## Prerequisites
Students can create and save an HTML file, link a CSS file, and preview a page in Chrome.

## Class plan (120 minutes)
20 min explanation · 4 min theory review · 30 min instructor demo · 62 min student practice · 4 min review.

## Learning resources
- **Read:** [MDN: What is JavaScript?](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/What_is_JavaScript)
- **Read:** [MDN: A first splash into JavaScript](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/A_first_splash)
- **Watch (optional):** [JavaScript for Beginners — Programming with Mosh](https://www.youtube.com/watch?v=W6NZfCO5SIk). This is a longer video; use only the introduction and console sections as a preview.

## Practical result
A webpage linked to `script.js`, with messages visible in the browser console.

## Homework
Create a page called "My JavaScript Practice". Link an external `script.js` file and print at least five messages in the console. Include your first name only if you are comfortable; do not publish personal contact details.

## Quick check
1. What does JavaScript add to a webpage?
2. What is the browser console used for?
3. What does `console.log()` do?
4. Why do we use an external JavaScript file?
5. What does `defer` help with?

## Completion check
Student can open DevTools, view console messages, and correct one simple script-link or spelling error.
