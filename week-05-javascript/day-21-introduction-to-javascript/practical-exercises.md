# Day 21 Practical Exercises — First JavaScript

## Exercise 1 — Create the files (8 min)
Create a folder called `day-21-practice`. Inside it create `index.html` and `script.js`.

## Exercise 2 — Link the script (8 min)
Add the external script element inside the HTML head:
```html
<script src="script.js" defer></script>
```
Check the filename letter by letter.

## Exercise 3 — Print messages (12 min)
In `script.js`, write:
```javascript
console.log("Hello, JavaScript!");
console.log("This is my first program.");
console.log("I can read the browser console.");
```
Save your files.

## Exercise 4 — Open the Console (10 min)
Open the page in Chrome. Open DevTools, choose Console, and find all three messages.

## Exercise 5 — Edit and debug (12 min)
Change one message. Save and refresh. Then temporarily change the script filename in HTML, observe what happens, and restore the correct name.

## Required independent task (20 min)
Write at least five useful messages in the console. Add one single-line comment explaining what your program does.

## Checklist
- [ ] HTML and JavaScript files are in the correct project folder.
- [ ] The external script is linked correctly.
- [ ] The script uses `console.log()`.
- [ ] Five messages appear in Console.
- [ ] One comment is included.
- [ ] Student can explain how to refresh and view output.

## Optional challenge
Print a numbered list of three learning goals.

## Troubleshooting
Check the Console for errors, verify the script path, save both files, and refresh the browser. Remember that Console is different from the Elements tab.
