# Day 21 Homework — My First JavaScript Page

## Task
Create a small webpage called **My JavaScript Practice** and connect an external JavaScript file.

## Requirements
- Files named `index.html` and `script.js`.
- External script connected with `defer`.
- At least five meaningful `console.log()` messages.
- At least one comment in the JavaScript file.
- Page opens in Chrome and messages appear in Console.

## Submit
Submit the project folder or both files. Add a short note explaining how you opened the Console.

## Optional challenge
Print three goals you have for learning web development.

## Safety
Do not include passwords, private email addresses, phone numbers, or home addresses in your code or screenshots.
