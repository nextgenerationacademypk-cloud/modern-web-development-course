1. Why are functions useful?

   - B. They replace HTML

2. In `function greet(name) {}`, what is `name`?

   - B. An HTML tag
   - C. A browser tab

3. In `greet("Amina")`, what is `"Amina"`?

   - B. A function name
   - C. A return keyword

4. What does `return` do?

   - B. Opens DevTools
   - C. Changes the page colour

5. Which statement is correct?
   - A. `console.log()` displays a value; `return` gives a value back
   - B. They always do exactly the same thing
