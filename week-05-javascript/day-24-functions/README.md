# Day 24 — Functions

## Lesson goal
Create reusable blocks of code using functions, pass information through parameters, and return results.

## Learning outcomes
- Explain why functions help organise code.
- Declare and call a function.
- Use parameters and arguments.
- Return a value with `return`.
- Test a function with more than one input.

## Class plan (120 minutes)
20 min explanation · 4 min theory review · 30 min instructor demo · 62 min student practice · 4 min review.

## Learning resources
- **Read:** [MDN: Functions — reusable blocks of code](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/Functions)
- **Read:** [MDN: Function return values](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/Return_values)
- **Watch (optional):** [JavaScript for Beginners — Programming with Mosh](https://www.youtube.com/watch?v=W6NZfCO5SIk), selected section about functions.

## Practical result
A set of small reusable calculator functions for addition, subtraction, and multiplication.

## Homework
Write functions to calculate the area of a rectangle and convert minutes to seconds. Test each function with at least two inputs.

## Quick check
1. What is a function?
2. What is a parameter?
3. What is an argument?
4. What does `return` do?
5. What is the difference between returning and logging a value?

## Completion check
Student writes, calls, and tests at least two functions that return calculated values.
