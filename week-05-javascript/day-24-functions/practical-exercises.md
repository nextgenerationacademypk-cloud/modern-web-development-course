# Day 24 Practical Exercises — Reusable Functions

## Exercise 1 — First function (8 min)
Write a function called `showWelcome` that prints a welcome message. Call it once.

## Exercise 2 — Add a parameter (10 min)
Write `greetStudent(studentName)`. Call it with two different names.

## Exercise 3 — Return a result (12 min)
Write `addNumbers(a, b)` so it returns the sum. Store the returned value and print it.

## Exercise 4 — More calculator functions (12 min)
Write and test:
- `subtractNumbers(a, b)`
- `multiplyNumbers(a, b)`

## Exercise 5 — Use a condition in a function (8 min)
Write `getPassMessage(score)` that returns "Pass" for 60 or above and "Keep practising" otherwise.

## Required independent task (20 min)
Create a mini calculator library with addition, subtraction, and multiplication functions. Call each function at least twice with different values.

## Checklist
- [ ] Declares at least three functions.
- [ ] Calls each function.
- [ ] Uses parameters.
- [ ] Uses arguments when calling.
- [ ] Returns calculation results.
- [ ] Tests more than one input.

## Optional challenge
Create a function that returns the larger of two numbers.

## Troubleshooting
Check function names, parentheses, parameter names, and whether you used `return` when the result needs to be used elsewhere.
