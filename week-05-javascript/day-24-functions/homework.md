# Day 24 Homework — Useful Functions

## Task
Write two reusable functions.

### Function 1 — Rectangle area
Create `calculateRectangleArea(width, height)` that returns width multiplied by height.

### Function 2 — Minutes to seconds
Create `convertMinutesToSeconds(minutes)` that returns minutes multiplied by 60.

## Requirements
- Use descriptive function names.
- Use parameters.
- Return results.
- Call each function at least twice with different values.
- Print the returned results with clear labels.

## Submit
Submit the HTML and JavaScript files and briefly explain one parameter and one returned value.

## Optional challenge
Write a function that calculates a 10% discount from a given price.
