# Project 2 — Academy Information Website

**Suggested week:** 3

## Goal
Build a simple information website for a fictional academy using HTML and CSS.

## Required sections
- Header with academy name
- Navigation links
- Welcome message
- Three course or service cards
- About section
- Contact information
- Footer

## Styling requirements
- External CSS file
- Consistent colours and fonts
- Comfortable spacing
- Card layout
- Flexbox used at least once
- Clear hover style for links or buttons

## Steps
1. Plan the sections.
2. Build semantic HTML.
3. Connect `style.css`.
4. Set global font and colours.
5. Style the header and navigation.
6. Build course cards.
7. Style the footer.
8. Test all links and inspect the page.

**Extra challenge:** Add a second page with more information about one course.
