# Project 1 — Personal Profile Website

**Suggested weeks:** 1–2

## Goal

Create a simple webpage that introduces a person.

## Required content

- Page title
- Main heading
- Short introduction
- Three interests
- Education or skills section
- Contact link or practice contact form
- At least one image with useful alternative text

## Steps

1. Create a project folder.
2. Create `index.html`.
3. Add the basic HTML document structure.
4. Add headings and paragraphs.
5. Add a list of interests.
6. Add a link and an image.
7. Add semantic sections.
8. Open the page in a browser and check it.

## Extra challenge

Create a second page named `about.html` and link to it from the home page.

## Success checklist

- [ ] HTML file opens in the browser.
- [ ] Content has a clear heading structure.
- [ ] Link works.
- [ ] Image has useful alt text.
- [ ] Page title is meaningful.
