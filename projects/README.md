# Guided Student Projects

These projects grow in difficulty as students learn new skills. Students should build them in class and improve them at home.

| Project | Suggested week | Main skills |
|---|---:|---|
| Personal profile website | 1–2 | HTML structure and content |
| Academy information website | 3 | CSS, box model, Flexbox |
| Responsive landing page | 4 | Mobile-first CSS, media queries, Grid |
| Calculator | 5 | JavaScript variables, functions, conditions |
| To-do list app | 6 | DOM, events, input handling |
| Final multi-page website | 8 | Combined course skills, GitHub, deployment |

Each project brief explains the expected result and a suggested feature list. Keep projects small enough to complete with the skills taught so far.
