# Final Project Starter

This starter helps beginners organise the final project. It is a starting point, not a finished website. Students should customise the content, styling, and code and be able to explain their work.

## Project scope

Build one responsive page with four sections: Home, About, Services or Courses, and Contact. Add two simple JavaScript interactions practised in class.

## Starter files

The starter files are in the [starter folder](starter/):
- [index.html](starter/index.html)
- [styles.css](starter/styles.css)
- [script.js](starter/script.js)

## Folder structure

```text
final-website/
├── index.html
├── styles.css
├── script.js
└── images/
```

## Start the project

1. Download or copy the three files from the starter folder into a new project folder.
2. Open the project folder in Visual Studio Code.
3. Replace sample text with your own topic and content.
4. Add suitable images to an `images` folder and use relative image paths.
5. Change colours, spacing, and layout to create your own design.
6. Preview in Chrome or with Live Server.
7. Test at mobile and desktop widths.
8. Push the finished project to GitHub and publish with GitHub Pages.

## Required student work

- Keep the four main sections.
- Make navigation links work.
- Add useful alternative text to informative images.
- Keep two simple JavaScript interactions and customise them for your website.
- Test the page and fix visible issues.
- Explain the code you submit.

The sample contact form only demonstrates browser-side form validation and feedback. It does not send messages or store information. Do not add passwords, private contact details, or secret keys to the website or GitHub repository.
