# Final Project Starter

This starter helps beginners organise the final project. It is a starting point, not a finished website. Students must add their own content, styling, and JavaScript.

## Project scope

Build one responsive page with four sections: Home, About, Services or Courses, and Contact. Add two simple JavaScript interactions practised in class.

## Folder structure

```text
final-website/
├── index.html
├── styles.css
├── script.js
└── images/
```

## Start the project

1. Copy the starter files into a new folder.
2. Open the folder in Visual Studio Code.
3. Replace sample text with your own topic and content.
4. Add suitable images to the images folder.
5. Preview in Chrome or with Live Server.
6. Test at mobile and desktop widths.
7. Push the finished project to GitHub and publish with GitHub Pages.

## Required student work

- Keep the four main sections.
- Make navigation links work.
- Add useful alternative text to informative images.
- Complete two simple JavaScript interactions.
- Test the page and fix visible issues.
- Explain the code you submit.

Do not add passwords, private contact details, or secret keys to the website or GitHub repository.
