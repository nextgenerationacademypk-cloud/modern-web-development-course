# Project 5 — To-do List App

**Suggested week:** 6

## Goal
Build a small app that lets a user add and remove tasks.

## Required features
- Text input for a task
- Add button
- Task list
- Remove button for each task
- Helpful message when the input is empty

## Suggested build steps
1. Create the input, button, and empty list in HTML.
2. Select the elements with JavaScript.
3. Listen for the add button click.
4. Read and trim the input value.
5. If the value is empty, show a message.
6. Create a list item and a remove button.
7. Add the new item to the page.
8. Clear the input after adding a task.
9. Test adding and removing several tasks.

**Extra challenge:** Add a completed state that visually marks a task as finished.

This is a browser practice app. It does not require accounts, a database, or a server.
