# Project 4 — Basic Calculator

**Suggested week:** 5

## Goal
Use JavaScript to perform basic arithmetic.

## Required operations
- Addition
- Subtraction
- Multiplication
- Division

## Requirements
- Read two numbers.
- Let the user choose an operation.
- Display the result.
- Handle division by zero with a helpful message.
- Use functions to organise the calculation.
- Keep the interface simple and readable.

## Suggested build steps
1. Create the HTML inputs and buttons or operation selector.
2. Add a JavaScript file.
3. Read the input values.
4. Convert input text to numbers.
5. Write one function for the calculation.
6. Display the result.
7. Test positive, negative, decimal, and zero values.

**Extra challenge:** Add a clear button that resets the inputs and result.
