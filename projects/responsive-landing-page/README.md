# Project 3 — Responsive Landing Page

**Suggested week:** 4

## Goal
Create a landing page that adapts to different screen sizes.

## Required sections
- Header and navigation
- Main welcome or hero section
- Call-to-action link or button
- Three feature cards
- About or benefits section
- Footer

## Technical requirements
- Mobile-first CSS
- At least two media query breakpoints
- Flexbox or Grid
- Responsive images
- No unwanted horizontal scrolling
- Readable text on a small screen

## Testing
Use Chrome DevTools device mode. Check a narrow mobile width, a tablet width, and a desktop width. Also resize the browser manually.

**Extra challenge:** Create a responsive card grid that changes from one column to two or three columns.
