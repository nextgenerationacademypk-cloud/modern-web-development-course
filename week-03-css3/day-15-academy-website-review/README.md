# Day 15 — CSS Integration and Academy Information Website

**Week:** 3 · **Session:** 15 of 40 · **Duration:** 120 minutes

Students combine external CSS, selectors, typography, box-model spacing, and Flexbox in one small academy website.

## Learning outcomes
- Build a styled page with a header, welcome section, three course cards, and footer.
- Reuse CSS classes for repeated cards.
- Use Flexbox on the parent card container.
- Explain the CSS choices used in the project.
