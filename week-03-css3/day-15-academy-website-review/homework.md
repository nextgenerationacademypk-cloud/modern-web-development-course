# Day 15 Homework — Academy Information Website

## Task
Finish or improve your Week 3 academy information website.

## Required content
- Header with academy name and navigation.
- Welcome section with a heading and short introduction.
- Three course cards.
- About section.
- Footer.

## Required CSS
- External stylesheet.
- Readable typography and a consistent colour palette.
- Reusable class for course cards.
- Padding, border, and margin for spacing.
- Flexbox on the parent of the course cards.

## Submit
- HTML file.
- CSS file.
- One screenshot in Chrome.

## Explain in your own words
1. Which selector did you reuse?
2. Which property creates space inside a card?
3. Which property separates a card from other elements?
4. Which element is the flex container?

Do not add JavaScript or Tailwind for this task. Responsive design is the focus of Week 4.
