# Homework — Day 15: Academy Information Website

Finish or improve your academy information website.

Required content:
- Header with academy name and navigation.
- Welcome section with a heading and short introduction.
- Three course cards.
- Footer with short closing information.

Required CSS:
- External stylesheet.
- Readable typography and a consistent colour palette.
- Reusable class for course cards.
- Padding and margin for spacing.
- Flexbox on the parent of the course cards.

Save both files and check the page in Chrome. Be ready to explain one selector, one spacing property, and one Flexbox property.

Do not add JavaScript or Tailwind for this task. Responsive design is the focus of Week 4.
