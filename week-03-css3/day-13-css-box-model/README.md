# Day 13 — The CSS box model

**Week:** 3 · **Session:** 13 of 40 · **Duration:** 120 minutes

## Purpose
Explain content, padding, border, and margin from the inside out. Practise width, max-width, padding, border, border-radius, margin, and box-sizing: border-box.

## Prerequisite
Students have completed Week 2 HTML lessons and can preview an HTML page.

## Learning outcome
Describe the box model and create a centred card with controlled width, padding, border, and margin.
