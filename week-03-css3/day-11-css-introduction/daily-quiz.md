# Day 11 Daily Quiz — CSS Basics

**Total:** 10 marks

## Part A — Multiple choice (1 mark each)
1. What does CSS mainly control?
   - A. Page presentation
   - B. Internet connection
   - C. File storage
   - D. Email messages
2. In `h1 { color: blue; }`, what is `h1`?
   - A. Value
   - B. Selector
   - C. Property
   - D. File name
3. Which HTML element connects an external stylesheet?
   - A. `<css>`
   - B. `<stylelink>`
   - C. `<link>`
   - D. `<script>`
4. Where should the stylesheet link normally go?
   - A. Inside `head`
   - B. Inside every paragraph
   - C. After the closing `html` tag
   - D. Inside the CSS file

## Part B — Short answers (2 marks each)
5. Explain one difference between HTML and CSS.
6. If both files are in the same folder, write the correct stylesheet link.

## Part C — Practical (2 marks)
7. Write or show a CSS rule that changes paragraph text colour.

**Review focus:** Students should identify a selector and correctly connect an external stylesheet. Keep any instructor answer key outside this public repository.
