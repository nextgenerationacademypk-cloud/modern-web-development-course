# Day 11 Homework — My First Stylesheet

## Task
Use your Week 2 profile page or make a fictional profile page. Connect an external file named `styles.css`.

Your page must include:
1. One main heading and two paragraphs.
2. A background colour.
3. A different heading colour.
4. A readable paragraph font size.
5. A working external stylesheet link.

## Submit
- `index.html`
- `styles.css`
- One screenshot showing the page in Chrome.

## Answer in your own words
1. What is the job of HTML?
2. What is the job of CSS?
3. Which HTML element connects your CSS file?

Type and understand your own code. Use fictional details and do not publish private contact information.
