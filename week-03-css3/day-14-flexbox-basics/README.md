# Day 14 — Flexbox Layout

**Week:** 3 · **Session:** 14 of 40 · **Duration:** 120 minutes

Learn to arrange items in rows and columns using Flexbox.

## Learning outcomes
- Create a flex container with display: flex.
- Use flex-direction, justify-content, align-items, gap, and flex-wrap.
- Arrange a navigation row and a group of cards.
