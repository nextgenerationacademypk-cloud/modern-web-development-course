# Modern Web Development — Complete Beginner to Practical Developer

**Next Generation Academy · Seni Gumbat, Kohat, Pakistan**

A practical, instructor-led introduction to modern website development. This course is designed for complete beginners. No previous programming experience is required.

## Course at a glance

| Item | Details |
|---|---|
| Duration | 8 weeks |
| Schedule | 5 days per week |
| Sessions | 40 sessions |
| Session length | 2 hours |
| Total learning time | 80 hours |
| Learning approach | 80% practical, 20% theory |
| Language | Simple English |
| Level | Complete beginner |

## Before the 8-week course

Students who have not completed basic computer training should complete the [Pre-course Digital Readiness Workshop](pre-course-digital-readiness/README.md) first. Students who have already completed the academy's Basic Computer & AI Foundation Course should use the workshop readiness checklist as a short diagnostic and complete only the catch-up topics they need. The workshop is a recommended 4-hour preparation activity and is separate from the 40 official course sessions. GitHub account creation is introduced later, in Week 7.

## What students will learn

- Understand how websites and the web work.
- Build well-structured pages with HTML5.
- Style pages with CSS3 and create responsive layouts.
- Understand the basics of Tailwind CSS and use utility classes.
- Write beginner JavaScript and make pages interactive.
- Use the DOM to update page content and respond to user actions.
- Save work with Git, share code with GitHub, and publish a website.
- Plan, build, test, and present a responsive website.

## Technology covered

HTML5 · CSS3 · Responsive Web Design · Introductory Tailwind CSS · JavaScript · DOM · Git · GitHub · GitHub Pages

This course focuses on strong foundations. React, Next.js, Node.js, databases, TypeScript, and server-side programming are outside this beginner course and may be covered in a later course.

## How each class works

Each two-hour class follows this pattern:

- 20 minutes: explanation and new ideas
- 4 minutes: quick theory review
- 30 minutes: instructor demonstration and guided coding
- 62 minutes: student practical work
- 4 minutes: practical review and questions

That gives students approximately 20% theory and 80% practical learning. The instructor may adjust individual activity timings when students need more support, while keeping the overall learning balance.

## Assessment and completion

Students earn up to 100 marks:

- Weekly practical work: 30
- Homework: 15
- Mid-course practical exam: 15
- Final project: 30
- Theory/viva: 10

Completion requires at least 80% attendance (32 of 40 sessions), submission of required assessment work, a pass in the mid-course practical exam (at least 9/15), submission and presentation of the final project, and at least 60/100 overall. See the [Assessment Policy](course-outline/assessment-policy.md) and [Assessment Rubrics](assessments/assessment-rubrics.md).

## Final project

Each student builds and publishes a responsive website with Home, About, Services or Courses, and Contact sections or pages. A single-page site with these four sections can earn full marks; separate pages are an optional extension. The project includes working navigation, consistent CSS styling, at least two simple JavaScript features, a mobile-friendly layout, a GitHub repository, and a live website URL.

Students may use traditional CSS. Tailwind CSS is optional and is not a requirement for the final project. The [starter structure](projects/final-project/starter/) and staged milestones support beginners.
