# Day 32 Homework — Commit History

## Task
Use Git to track your practice website. Make at least three commits:
1. Create the HTML page.
2. Add or improve CSS.
3. Update content or fix a layout issue.

## Submit
- Screenshot of git log --oneline.
- A short list of your three commit messages.
- One sentence explaining the difference between staging and committing.

## Marking — 5 marks
- Repository initialised correctly: 1
- Changes staged correctly: 1
- Three commits created: 2
- Explanation is correct: 1

Do not upload secrets or private data.
