# Day 32 — Git Commands and Commits

**Week:** 7 | **Session:** 32 | **Duration:** 120 minutes

## Purpose
Use a small set of Git commands to create a local repository and save meaningful project snapshots.

## Outcomes
Students can initialise a repository, inspect status, stage selected files, commit changes, and view commit history.

## 120-minute plan
20 min explanation; 4 min review; 30 min demo; 62 min practical; 4 min review.

## Core commands
~~~bash
git init
git status
git add index.html
git add .
git commit -m "Create first webpage"
git log --oneline
~~~

## Required result
A small website folder tracked by Git with at least two commits.

## Learning links
- Required: [Git — Recording Changes](https://git-scm.com/book/en/v2/Git-Basics-Recording-Changes-to-the-Repository)
- [Git status](https://git-scm.com/docs/git-status)
- [Git commit](https://git-scm.com/docs/git-commit)

## Scope
Teach init, status, add, commit, and log. Explain that add stages changes and commit records staged changes. Avoid branches, merge conflicts, reset, rebase, and advanced recovery.
