# Day 35 — Tailwind CSS Introduction and Week 7 Review

**Week:** 7 | **Session:** 35 | **Duration:** 120 minutes

## Purpose
Understand utility-first CSS and try a small set of Tailwind CSS utilities after learning HTML, CSS, Flexbox, Grid, and responsive design.

## Outcomes
Students can explain utility classes, recognise common spacing, colour, sizing, flex, grid, and responsive-prefix utilities, and style a simple card.

## 120-minute plan
20 min explanation; 4 min review; 30 min instructor demo; 62 min practical; 4 min review.

## Required result
A simple card or course information section styled with Tailwind utility classes in the official Play CDN classroom demo.

## Learning links
- Required: [Tailwind CSS — Play CDN](https://tailwindcss.com/docs/installation/play-cdn)
- [Tailwind CSS — Utility-first fundamentals](https://tailwindcss.com/docs/styling-with-utility-classes)
- [Tailwind CSS — Responsive design](https://tailwindcss.com/docs/responsive-design)

## Important
Use the current official Tailwind v4 documentation. The Play CDN is for development and learning only, not production. Do not teach old v3 installation instructions. Tailwind is optional for the final project; traditional CSS remains fully acceptable.
