# Day 35 Homework — Tailwind Card

## Task
Create one course card using Tailwind in the classroom demo or reproduce the same design using traditional CSS.

## Submit
- Screenshot of your card.
- The HTML containing the classes or your CSS file.
- Four short notes explaining the purpose of four classes or CSS declarations.

## Marking — 5 marks
- Card structure and content: 1
- Spacing and typography: 1
- Colour and visual clarity: 1
- Responsive behaviour or layout check: 1
- Correct explanation of four utilities or CSS rules: 1

Tailwind is optional in the final course project. Do not publish the Play CDN as a production setup.
