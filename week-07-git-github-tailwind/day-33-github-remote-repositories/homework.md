# Day 33 Homework — GitHub Repository

## Task
Publish your practice website repository and make one further update.

## Submit
- Repository URL.
- Screenshot showing the repository file list.
- Your latest commit message.
- One sentence explaining the difference between commit and push.

If you cannot create an account, ask your instructor for an approved alternative. Do not send credentials to anyone.

## Marking — 5 marks
- Repository created or approved alternative completed: 1
- Local remote configured correctly: 1
- Initial push successful: 1
- Follow-up commit and push: 1
- Correct explanation and safe handling: 1
