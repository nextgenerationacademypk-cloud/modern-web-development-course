# Day 33 — GitHub and Remote Repositories

**Week:** 7 | **Session:** 33 | **Duration:** 120 minutes

## Purpose
Create a GitHub repository and connect it to a local Git project.

## Outcomes
Students can sign in to GitHub, create an appropriately named repository, add a remote, push commits, and verify files online.

## 120-minute plan
20 min explanation; 4 min review; 30 min demo; 62 min practical; 4 min review.

## Core commands
~~~bash
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git branch -M main
git push -u origin main
~~~

If a repository already has a remote, inspect it with git remote -v rather than adding a duplicate.

## Required result
Each student publishes a practice website repository to their own GitHub account.

## Learning links
- Required: [GitHub Docs — Create a repository](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-new-repository)
- [GitHub Docs — Adding a remote](https://docs.github.com/en/get-started/git-basics/managing-remote-repositories)
- [GitHub Docs — Authentication](https://docs.github.com/en/authentication)

## Safety
Use personal accounts according to age and platform requirements. Never share passwords, recovery codes, or tokens. Use Git Credential Manager or the browser/device sign-in flow when prompted; do not paste account passwords into terminal commands.
