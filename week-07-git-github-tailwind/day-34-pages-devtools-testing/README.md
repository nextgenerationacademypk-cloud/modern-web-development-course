# Day 34 — GitHub Pages, Chrome DevTools and Testing

**Week:** 7 | **Session:** 34 | **Duration:** 120 minutes

## Purpose
Publish a static website with GitHub Pages and practise checking it in Chrome DevTools.

## Outcomes
Students can enable Pages for a repository, find the published URL, inspect an element, use the Console, test responsive widths, and follow a simple test checklist.

## 120-minute plan
20 min explanation; 4 min review; 30 min instructor demo; 62 min practical; 4 min review.

## Required result
A small static website is published with GitHub Pages and checked at desktop and mobile widths.

## Learning links
- Required: [GitHub Pages quickstart](https://docs.github.com/en/pages/quickstart)
- [Configure a publishing source](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
- [Chrome DevTools overview](https://developer.chrome.com/docs/devtools/overview/)
- [Device Mode](https://developer.chrome.com/docs/devtools/device-mode/)

## Scope
Teach the GitHub Pages branch/folder publishing option appropriate to the repository. GitHub Pages is for static websites; it does not run server-side code or databases. Explain that publication may take a short time and settings can vary by repository.
