# Day 34 Homework — Website Deployment Check

## Task
Publish your practice website with GitHub Pages and test it.

## Submit
- Published website URL.
- GitHub repository URL.
- A completed test checklist.
- One screenshot of the site at a narrow viewport.
- One issue you found and how you fixed it, or state that no issue was found.

## Marking — 5 marks
- Correct Pages configuration: 1
- Website opens at the published URL: 1
- CSS, images, and navigation tested: 1
- Narrow layout tested: 1
- Clear test note: 1

If your site is still deploying, submit a screenshot of the Pages settings and follow up with the published URL when available.
