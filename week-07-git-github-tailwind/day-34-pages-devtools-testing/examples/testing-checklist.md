# Static Website Test Checklist

- [ ] Published URL opens.
- [ ] Main page heading is visible.
- [ ] CSS loads.
- [ ] Images load and have suitable alt text.
- [ ] Navigation links work.
- [ ] JavaScript interactions work.
- [ ] No unexplained Console errors.
- [ ] Narrow layout has no unwanted horizontal scrolling.
- [ ] Wide layout is readable.
- [ ] No passwords, tokens, or private data are published.

If a test fails: reproduce the problem, inspect the relevant code, fix it locally, commit, push, and test again.
