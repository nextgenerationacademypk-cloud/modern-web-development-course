# Day 31 Practical Exercises — Git Foundations

## Exercise 1 — Explore the project
Open your practice website folder in VS Code. Identify index.html and styles.css.

## Exercise 2 — Open the terminal
In VS Code, open Terminal → New Terminal. Identify the prompt and the current folder.

## Exercise 3 — Check Git
Run:

~~~bash
git --version
~~~

Write down the version number. If it is not recognised, ask the instructor before changing system settings.

## Exercise 4 — Configure your commit identity
Use your own appropriate name and email:

~~~bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
~~~

Do not copy the example identity literally. Do not use a classmate's email.

## Required independent task
Create a folder named git-practice. Add a simple index.html file and open it in Chrome. Explain to a partner the difference between Git and GitHub.

## Checklist
- [ ] I can open the VS Code terminal.
- [ ] Git is installed or I have reported the setup issue.
- [ ] I can run git --version.
- [ ] I know what repository and commit mean.
- [ ] I can explain Git vs GitHub.

## Optional challenge
Write three short reasons why keeping a project history is useful.

## Troubleshooting
If git is not recognised, verify installation, close and reopen the terminal, and ask the instructor to check PATH. Do not download Git from unofficial websites.
