# Day 31 Homework — Git Vocabulary

## Task
Write a short explanation in your own words.

1. What is version control?
2. What is Git?
3. What is GitHub?
4. What is a repository?
5. What is a commit?

Also include the output of git --version if Git is installed on your computer.

## Marking — 5 marks
- Correct explanation of version control: 1
- Git and GitHub clearly distinguished: 2
- Repository and commit explained: 1
- Git version check or clear setup note: 1

Do not share passwords, tokens, or private account information.
