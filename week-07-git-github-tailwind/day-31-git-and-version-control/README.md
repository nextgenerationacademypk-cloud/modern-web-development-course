# Day 31 — Git and Version Control

**Week:** 7 | **Session:** 31 | **Duration:** 120 minutes

## Purpose
Understand why developers track changes and distinguish Git from GitHub.

## Outcomes
Students can explain version control, repository, commit, working folder, and history; check whether Git is installed; and create a practice project folder.

## 120-minute plan
20 min explanation; 4 min review; 30 min instructor demo; 62 min practical; 4 min review.

## Topics
- Why saving multiple copies can become confusing.
- Version control as a record of project changes.
- Git as a version-control tool that runs on the computer.
- GitHub as an online service for hosting Git repositories.
- Repository, commit, and project history.
- Installing Git from the official website and checking it in a terminal.

## Required result
Students explain Git vs GitHub and create a practice folder containing a simple HTML page.

## Learning links
- Required: [Git — About Version Control](https://git-scm.com/book/en/v2/Getting-Started-About-Version-Control)
- [Git official downloads](https://git-scm.com/downloads)
- [GitHub Docs — About Git](https://docs.github.com/en/get-started/using-git/about-git)

## Scope
Do not teach branching, merging, rebasing, SSH keys, or conflict resolution today. GitHub account creation and remote repositories are covered on Day 33.
