# Course Overview

## Course title

Modern Web Development — Complete Beginner to Practical Developer

## Audience

This course is for complete beginners who want to learn how to create websites. Students do not need previous coding experience.

## Duration and delivery

- 8 weeks
- 5 days each week
- 2 hours per day
- 40 sessions
- 80 total hours
- Instructor-led classroom learning
- 80% practical work and 20% theory

## Course purpose

Students learn the basic tools and skills needed to create, style, make interactive, test, and publish websites. The course builds one skill at a time and gives students regular coding practice.

## Main topics

1. Web and computer foundations
2. HTML5 page structure and content
3. CSS3 styling and layout
4. Responsive web design
5. Introductory Tailwind CSS
6. JavaScript foundations
7. DOM manipulation and browser events
8. Git and GitHub
9. Website testing and GitHub Pages deployment
10. Final website project

## Teaching method

The instructor explains a small topic, demonstrates it, and then guides students as they write code. Students complete independent tasks and homework. Every week includes a practical result.

## What this course does not cover

This is a foundation course. React, Next.js, Node.js, databases, TypeScript, server-side programming, and professional deployment pipelines are outside its 80-hour scope. They may be offered as a next-level course.
