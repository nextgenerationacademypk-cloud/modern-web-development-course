# Learning Outcomes

By the end of the course, a successful student should be able to:

## Web foundations
- Explain what a website, browser, web server, and URL are in simple terms.
- Create folders and files and use Visual Studio Code.
- Open and test a local webpage in a browser.

## HTML
- Create a valid basic HTML5 document.
- Add headings, paragraphs, links, images, lists, tables, and forms.
- Use semantic elements such as header, nav, main, section, and footer.

## CSS and responsive design
- Connect an external CSS file to an HTML page.
- Use selectors, colors, fonts, spacing, borders, and the box model.
- Build layouts with Flexbox and introductory CSS Grid.
- Use media queries and mobile-first thinking.
- Make pages usable on mobile, tablet, and desktop screens.

## Tailwind CSS
- Explain the utility-first approach.
- Recognise common spacing, colour, typography, layout, and responsive utility classes.
- Build a simple card or section using Tailwind utilities.

## JavaScript and DOM
- Use variables, data types, operators, conditions, functions, arrays, and loops.
- Select and update HTML elements with JavaScript.
- Respond to clicks and form events.
- Build simple interactive features and validate basic form input.

## Git, GitHub, and publishing
- Explain why version control is useful.
- Create a Git repository and save changes with commits.
- Push a project to GitHub.
- Publish a static website with GitHub Pages.
- Use browser developer tools for basic inspection and debugging.

## Final project
- Plan and build a responsive multi-page website.
- Test the website at different screen sizes.
- Publish the project and explain its main features.
