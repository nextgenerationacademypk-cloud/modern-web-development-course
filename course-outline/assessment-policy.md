# Assessment Policy

The course uses practical work as the main measure of learning. Students should write and explain their own code.

## Marks

| Assessment | Marks |
|---|---:|
| Weekly practical work | 30 |
| Homework | 15 |
| Mid-course practical exam | 15 |
| Final project | 30 |
| Theory and viva | 10 |
| **Total** | **100** |

## Completion requirements

A student should meet all of these requirements:

- Attend at least 80% of the 40 sessions.
- Submit the required assignments.
- Take and pass the mid-course practical exam.
- Submit and present the final project.
- Earn at least 60 marks out of 100.

## Final project marking guide

| Area | Marks |
|---|---:|
| HTML structure and content | 5 |
| CSS styling and layout | 5 |
| Responsive behaviour | 5 |
| JavaScript features | 5 |
| Navigation and usability | 3 |
| GitHub repository and live deployment | 4 |
| Presentation and explanation | 3 |
| **Total** | **30** |

## Fair assessment

- Explain the task and marking criteria before students begin.
- Give students time to ask questions.
- Assess working results and understanding, not copied code.
- Allow students to explain their decisions.
- Keep individual student marks private.
- Store instructor answer keys outside this public student repository.
