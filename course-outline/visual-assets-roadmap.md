## Screenshot capture note

Software screenshots should be captured from the instructor's actual current installation during lesson preparation. This is especially important for VS Code, GitHub, Tailwind CSS, Chrome DevTools, and GitHub Pages because their interfaces can change. Use original diagrams for concepts that do not depend on a software interface.
