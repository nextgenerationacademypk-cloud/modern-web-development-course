# Student Notes: Digital Readiness

Welcome! This workshop prepares you to start learning website development. You do not need programming experience.

## 1. Basic computer skills

A computer has hardware (the physical parts) and software (the programs you use).

Important words:
- **Desktop:** The main screen after you sign in.
- **Window:** The area where an app is open.
- **Application (app):** A program, such as Chrome or VS Code.
- **File:** A saved item, such as a picture or HTML document.
- **Folder:** A place used to organise files.
- **File name and extension:** In `index.html`, the name is `index` and the extension is `.html`.

Useful actions:
- Click once to select; double-click to open.
- Use right-click to see more actions.
- `Ctrl + C` copies, `Ctrl + V` pastes, `Ctrl + X` cuts.
- `Ctrl + S` saves, `Ctrl + Z` undoes.
- Create clear folder and file names. Avoid names such as `new folder 2` or `final-final-really-final`.

## 2. Internet and Chrome

The **internet** connects computers around the world. The **web** is a service that lets you open websites through a browser.

In Chrome:
- The **address bar** shows a website address and can also search the web.
- A **tab** lets you open another page without closing the first.
- A **link** takes you to another page or resource.
- A **download** saves a file from the internet to your device.

Safe browsing:
- Check the website address before entering information.
- Do not open unexpected downloads or suspicious links.
- Do not enter passwords on a page unless you trust the website and expected the sign-in request.
- Ask the instructor if a page or message looks unusual.

## 3. Email basics

An email address is used to send and receive electronic messages. It usually looks like `person@example.com`.

Common email actions:
- **Inbox:** Messages you receive.
- **Compose:** Start a new message.
- **To:** The recipient's email address.
- **Subject:** A short description of the message.
- **Send:** Send the message.
- **Reply:** Respond to a message.
- **Attachment:** A file sent with a message.

Email safety:
- Never share your password or one-time verification code.
- Use a password that is hard to guess and not used on other sites.
- Check the recipient before sending.
- Be careful with unexpected attachments and links.
- Keep account recovery information private and accurate.
- Follow provider age requirements and academy policy. Do not use a false date of birth.

## 4. Visual Studio Code (VS Code)

VS Code is a code editor. It helps you create and edit website files.

Important areas:
- **Explorer:** Shows the files and folders in your project.
- **Editor:** The main area where you type code.
- **File tab:** Shows the file currently open.
- **Save:** Stores your latest changes.

Basic workflow:
1. Open VS Code.
2. Choose **File → Open Folder**.
3. Select your website project folder.
4. In Explorer, create a file named `index.html`.
5. Type or edit content and press `Ctrl + S`.

## 5. Preview your webpage

A browser displays your webpage. VS Code edits the file; Chrome displays it.

With Live Server:
1. Open `index.html` in VS Code.
2. Right-click in the editor and choose **Open with Live Server**, or use the **Go Live** button if available.
3. Chrome opens a local preview.
4. Save changes in VS Code. The browser usually refreshes automatically.

If Live Server is not available, you can open the `index.html` file directly in Chrome. Save your changes and refresh the browser.

## 6. Remember these ideas

- A folder keeps project files together.
- A browser displays a webpage.
- VS Code edits website files.
- Saving is different from publishing. A local preview is visible on your computer; a published website is available online.
- Git and GitHub are later course topics. You do not need to learn them today.
