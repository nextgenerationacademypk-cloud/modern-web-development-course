# Pre-course Digital Readiness Workshop

**For:** Modern Web Development — Complete Beginner to Practical Developer  
**Provider:** Next Generation Academy, Seni Gumbat, Kohat  
**Recommended duration:** 4 hours (240 minutes)  
**Timing:** Before the official 8-week, 40-session course  
**Level:** No previous computer or programming experience required

## Purpose

This workshop helps students become comfortable with the basic computer, browser, email, and editor tasks they will need in the main course. It is not a programming class and does not replace any of the 40 course sessions.

Students do not need to know HTML, CSS, JavaScript, Git, or GitHub before attending.

## Workshop plan

| Part | Time | Main skills |
|---|---:|---|
| 1. Computer and files | 45 min | Mouse, keyboard, windows, apps, folders, files, copy, paste, save |
| 2. Internet and browser | 45 min | Chrome, address bar, search, tabs, links, downloads |
| 3. Email basics | 60 min | Email address, inbox, compose, reply, attachments, verification, account safety |
| 4. VS Code setup | 60 min | Open a project folder, create and save a file, install Live Server, preview a page |
| 5. Readiness check | 30 min | Complete the essential tasks independently or with light support |

## Important teaching decision

**Do not teach GitHub account creation in this workshop.** Introduce GitHub in Week 7, close to the lessons where students will use it. This reduces early overload. Students can use the workshop to learn safe email basics; the instructor can explain later that a GitHub account uses an email address.

## Preparation

Before the workshop, the academy should arrange:
- A computer for each student where possible; otherwise, one computer for each pair.
- A working internet connection.
- Google Chrome and Visual Studio Code, installed in advance if students do not have permission to install software.
- The Live Server extension in VS Code, or permission to install it during the workshop.
- A projector or large display for demonstrations.
- A safe way for students to access their own email accounts.

## Safety and privacy

- Students must never tell the instructor or another student their password or verification code.
- Do not create one shared email account for the class.
- Use a student's own account only when the student is eligible under the email provider's age rules and academy policy. If not, use a permitted supervised alternative; do not enter a false birth date.
- Do not ask students to write passwords on a public board or submit them in homework.
- Use fictional names and sample information in practice webpages.
- The workshop does not require students to publish personal contact details.

## Completion

A student is ready for the main course when they can, with reasonable confidence:
1. Open Chrome and visit a web address.
2. Search for a learning resource and open a link.
3. Create and find a project folder.
4. Create, save, and reopen a file.
5. Open the project folder in VS Code.
6. Open an HTML file in Chrome and refresh after saving.
7. Access their email safely, or explain the approved support arrangement if they cannot yet use an account.

Use the [readiness checklist](readiness-checklist.md) to record support needs. A student who needs more practice should receive support, not be excluded automatically.
