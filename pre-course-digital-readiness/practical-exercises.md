# Practical Exercises: Digital Readiness

Work carefully. Ask for help when you need it. Do not share passwords or verification codes.

## Exercise 1 — Use the computer

1. Point to the desktop, taskbar, and an open window.
2. Open Chrome from the desktop or app menu.
3. Switch between Chrome and another open window.
4. Practise `Ctrl + C`, `Ctrl + V`, `Ctrl + S`, and `Ctrl + Z` in a safe practice document.
5. Create a folder named `my-first-website`.
6. Open the folder and create a simple text file.
7. Rename the file and find it again.

**Expected result:** You can create a folder and locate a file inside it.

## Exercise 2 — Use Chrome

1. Open Chrome.
2. Type a trusted website address in the address bar.
3. Open a new tab.
4. Search for “HTML beginner lesson”.
5. Open a suitable result after checking the address.
6. Return to the search tab.
7. Download a harmless practice file provided by the instructor.
8. Find the downloaded file in Chrome's downloads list or the Downloads folder.

**Expected result:** You can use the address bar, tabs, search, links, and downloads.

## Exercise 3 — Email basics

1. Identify the inbox, Compose, recipient field, subject field, and Send button.
2. If you already have an eligible email account, sign in privately. Do not show your password to anyone.
3. If the instructor has arranged a safe practice recipient, send a short message with the subject “Practice message”.
4. Reply to a practice message if one is available.
5. Practise attaching only the harmless sample file supplied by the instructor.
6. Sign out on a shared computer when finished.

If you cannot access an account, do not create one using false information. Ask the instructor for the approved alternative.

**Expected result:** You understand the basic parts of email and can use an approved practice method safely.

## Exercise 4 — VS Code and project folder

1. Open VS Code.
2. Choose **File → Open Folder**.
3. Select `my-first-website`.
4. Find the Explorer panel.
5. Create a file named `index.html`.
6. Type the sample HTML shown by the instructor.
7. Press `Ctrl + S`.
8. Confirm that the file appears in Explorer.

**Expected result:** VS Code shows your project folder and saved HTML file.

## Exercise 5 — Preview your page

1. Open `index.html` in VS Code.
2. Use Live Server if it is installed.
3. If Live Server is not available, open the file directly in Chrome.
4. Check that the heading and paragraph appear.
5. Change the heading in VS Code.
6. Save the file.
7. Check the updated page in Chrome. Refresh if needed.

**Expected result:** You can edit, save, and preview a local webpage.

## Optional challenge

Create a second file named `about.txt` inside your project folder. Write one sentence in it, save it, close it, and reopen it.

## Before you finish

- Keep your project folder in the location your instructor recommends.
- Do not delete the folder.
- Do not put passwords or private contact information in project files.
- Tell your instructor which step you want to practise again.
