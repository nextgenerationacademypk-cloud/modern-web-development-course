# Day 10 Practical Exercises — Semantic HTML and Profile Page Project

## What you will practise

You will use semantic HTML to complete a small personal profile website. This is the Week 2 mini-project. Keep it HTML-only; CSS will be taught in Week 3.

## Exercise 1 — Read the page map

Open `images/day-10-semantic-layout.svg`.

1. Find the header and navigation regions.
2. Find the main content region.
3. Find the sections and footer.
4. Explain the purpose of one semantic element in your own words.

## Exercise 2 — Guided practice

1. Open `examples/index.html`.
2. Identify `header`, `nav`, `main`, `section`, and `footer`.
3. Find the navigation links and the IDs they point to.
4. Click each navigation link in Chrome.
5. Change one section heading and its content.
6. Save and refresh the browser.

## Exercise 3 — Required mini-project: Personal profile website

Complete a simple profile page with these sections:

### Home
- A welcoming heading.
- A short introduction paragraph.

### About
- A paragraph with safe, fictional or non-sensitive personal information.

### Interests or Skills
- A list of at least three interests or beginner skills.
- One relevant image with appropriate alt text.

### Contact
- A safe contact heading or a sample contact form if your instructor approves.
- Do not publish your real phone number, home address, password, or private details.

### Required HTML structure

- A useful page `title`.
- One main `h1`.
- A semantic `header`, `nav`, `main`, and `footer`.
- At least three titled `section` elements.
- Navigation links that jump to the correct section IDs.
- At least one paragraph and one list.
- One image with useful alt text.

## Completion checklist

- [ ] My page has a clear title and one main heading.
- [ ] I used semantic page regions correctly.
- [ ] My sections have meaningful headings.
- [ ] Every navigation link jumps to the correct section.
- [ ] My image loads and has useful alt text.
- [ ] My content and code are readable.
- [ ] I can explain the purpose of the main semantic elements.
- [ ] I have not included private information.

## Optional challenge

Add one `article` containing a self-contained learning update. Explain why it makes sense as an article rather than just adding it for appearance.

## Troubleshooting

- If a navigation link does not jump, check that the fragment in `href` matches a section's `id`.
- If an image is missing, check its relative path and filename.
- If a section is difficult to understand, add a meaningful heading.
- If the page looks plain, that is expected: CSS begins in Week 3.

## Expected result

A complete, HTML-only personal profile website with semantic structure, useful content, a working navigation menu, a local image, and readable code.
