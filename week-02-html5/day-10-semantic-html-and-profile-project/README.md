# Day 10 — Semantic HTML and Profile Page Project

**Duration:** 120 minutes  
**Week:** 2 — HTML5 Page Structure

## Goal

Use meaningful page regions to complete a structured personal profile website.

## Learning outcomes

- Use header, nav, main, section, article, and footer.
- add in-page navigation.
- use headings to organise sections.
- review Week 2 HTML elements..

## Prerequisite

Complete Week 1. You should be able to open and save an HTML file in VS Code and preview it in Chrome or Live Server.

## Required tools

- VS Code
- Chrome
- Live Server extension

## 120-minute class plan

| Activity | Minutes |
|---|---:|
| Explanation | 20 |
| Theory review | 4 |
| Instructor demonstration and guided coding | 30 |
| Student practical work | 62 |
| Practical review | 4 |
| **Total** | **120** |

## Practical task

Complete a personal profile page with Home, About, Interests or Skills, and Contact sections using semantic HTML.
