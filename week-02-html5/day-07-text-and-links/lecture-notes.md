# Day 7 Lecture Notes — Text Formatting and Links

## Learning goal

Emphasise text appropriately and create useful hyperlinks.

## 1. Key ideas

Strong and em; line breaks only when appropriate; anchors; href; relative and absolute URLs; link text; opening external links.

HTML describes the meaning and structure of webpage content. Use an element because it describes the content, not simply because of how it looks. Keep your code indented so that nested parts are easy to read.

## 2. Important reminders

- Use strong and em for meaning and emphasis.
- Create links with a and href.
- Use clear link text and safe external-link habits.

## 3. Study the complete example

Open [examples/index.html](examples/index.html) in VS Code. Read it from the first line to the last line. Notice the document structure from Week 1, then identify today's new elements.

## 4. How to practise

1. Open your Week 2 project folder in VS Code.
2. Create or open `index.html`.
3. Type the example in small parts; do not paste it all without reading it.
4. Save the file.
5. Preview it in Chrome or Live Server.
6. Change the sample content to your own fictional practice content.
7. Check the result and fix mistakes.

## 5. Common mistakes

- Misspelling element names or attributes.
- Forgetting quotation marks around attribute values.
- Using a file path that does not match the actual folder and file name.
- Forgetting to save before refreshing the browser.
- Choosing an element for its visual appearance instead of its meaning.
