# Day 7 — Text Formatting and Links

**Duration:** 120 minutes  
**Week:** 2 — HTML5 Page Structure

## Goal

Emphasise text appropriately and create useful hyperlinks.

## Learning outcomes

- Use strong and em for meaning and emphasis.
- Create links with a and href.
- Use clear link text and safe external-link habits.

## Prerequisite

Complete Week 1 and be able to open and save an HTML file in VS Code and preview it in Chrome or Live Server.

## Required tools

- VS Code
- Chrome
- Live Server extension
- The Week 2 practice folder

## Class plan

| Activity | Minutes |
|---|---:|
| Explanation | 20 |
| Theory review | 4 |
| Instructor demonstration and guided coding | 30 |
| Student practical work | 62 |
| Practical review | 4 |
| **Total** | **120** |

## Topics

Strong and em; line breaks only when appropriate; anchors; href; relative and absolute URLs; link text; opening external links.

## Practical task

Add a useful resource-links section to your profile page with two external learning links and one link to a page section.
