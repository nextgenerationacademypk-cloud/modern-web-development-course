# Day 6 Homework — Headings and Paragraphs

## Task

Improve your About Me page with sections for introduction, education, and interests. Use one h1 and meaningful h2 headings.

## Rules

- Use only HTML elements taught so far.
- Do not add CSS or JavaScript yet.
- Use fictional content for classroom examples.
- Do not publish private phone numbers, home addresses, passwords, or personal information.
- Save the work in your Week 2 project folder.

## Submit

Bring your `index.html` file to the next class and be ready to explain two elements you used.
