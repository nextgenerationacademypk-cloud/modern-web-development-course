# Day 6 — Headings and Paragraphs

**Duration:** 120 minutes  
**Week:** 2 — HTML5 Page Structure

## Goal

Create readable page content with headings and paragraphs.

## Learning outcomes

- Use heading elements from h1 to h6.
- Write clear paragraphs with p.
- Organise a page with a logical heading order.

## Prerequisite

Complete Week 1 and be able to open and save an HTML file in VS Code and preview it in Chrome or Live Server.

## Required tools

- VS Code
- Chrome
- Live Server extension
- The Week 2 practice folder

## Class plan

| Activity | Minutes |
|---|---:|
| Explanation | 20 |
| Theory review | 4 |
| Instructor demonstration and guided coding | 30 |
| Student practical work | 62 |
| Practical review | 4 |
| **Total** | **120** |

## Topics

Heading levels; paragraph elements; heading order; readable content; the difference between a page title and a heading.

## Practical task

Create an About Me page with one h1, at least three h2 sections, and at least one paragraph in each section.
