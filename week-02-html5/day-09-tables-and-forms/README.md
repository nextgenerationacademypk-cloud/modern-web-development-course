# Day 9 — Tables and Forms

**Duration:** 120 minutes  
**Week:** 2 — HTML5 Page Structure

## Goal

Present simple data in a table and create a labelled sample form.

## Learning outcomes

- Use table, caption, thead, tbody, tr, th, and td.
- create form, label, input, textarea, and button.
- connect label for to input id.
- use suitable input types.
- understand that HTML alone does not send or store form data..

## Prerequisite

Complete Week 1. You should be able to open and save an HTML file in VS Code and preview it in Chrome or Live Server.

## Required tools

- VS Code
- Chrome
- Live Server extension

## 120-minute class plan

| Activity | Minutes |
|---|---:|
| Explanation | 20 |
| Theory review | 4 |
| Instructor demonstration and guided coding | 30 |
| Student practical work | 62 |
| Practical review | 4 |
| **Total** | **120** |

## Practical task

Build a weekly timetable and a sample contact form with name, email, and message fields.
