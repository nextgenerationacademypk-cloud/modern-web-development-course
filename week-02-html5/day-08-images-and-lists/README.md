# Day 8 — Images and Lists

**Duration:** 120 minutes  
**Week:** 2 — HTML5 Page Structure

## Goal

Add images with alternative text and organise information into lists.

## Learning outcomes

- Add an image with img and src.
- Write useful alt text for meaningful images.
- Create ordered and unordered lists.

## Prerequisite

Complete Week 1 and be able to open and save an HTML file in VS Code and preview it in Chrome or Live Server.

## Required tools

- VS Code
- Chrome
- Live Server extension
- The Week 2 practice folder

## Class plan

| Activity | Minutes |
|---|---:|
| Explanation | 20 |
| Theory review | 4 |
| Instructor demonstration and guided coding | 30 |
| Student practical work | 62 |
| Practical review | 4 |
| **Total** | **120** |

## Topics

Image files and folders; img; src; alt; image file paths; ul; ol; li; choosing the right list.

## Practical task

Create a page about a hobby with one relevant image, an unordered list of equipment, and an ordered list of steps.
