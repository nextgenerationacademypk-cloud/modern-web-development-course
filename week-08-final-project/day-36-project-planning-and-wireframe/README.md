# Day 36 — Final Project Planning and Wireframe

## Purpose

Choose a realistic website topic, identify its audience, plan the four required sections, sketch a wireframe, and prepare the starter folder.

## Learning outcomes

- Choose a suitable topic and audience.
- Describe the purpose of Home, About, Services or Courses, and Contact sections.
- Sketch a readable desktop and mobile page layout.
- Select two familiar JavaScript interactions.
- Create and inspect the supplied starter project folder.

## Before class

- Open the course [final project brief](../README.md).
- Keep the instructor-provided starter folder available.
- Remind students: a single-page site with the four required sections can earn full marks.

## 120-minute class plan

| Activity | Time |
|---|---:|
| Explain project brief and success criteria | 20 min |
| Recall the four required sections and project rules | 4 min |
| Instructor models choosing a topic and drawing a wireframe | 30 min |
| Students plan, sketch, and prepare their project folder | 62 min |
| Review each plan and approve scope | 4 min |
| **Total** | **120 min** |

## Practical work

1. Write a one-sentence purpose and identify the intended audience.
2. Plan a Home section with a heading, short introduction, and call to action.
3. Plan About, Services/Courses, and Contact content using short bullet points.
4. Draw a simple wireframe showing header, navigation, main sections, and footer.
5. Choose two interactions already practised, such as mobile navigation and FAQ show/hide.
6. Copy the instructor starter folder and open the folder in VS Code.

## Homework

- [ ] Complete the four-section content plan.
- [ ] Improve the wireframe so the order of content is clear.
- [ ] Collect or create two suitable images; save them in the project images folder and note their source.
- [ ] Write down the two JavaScript interactions and explain what each should do.
