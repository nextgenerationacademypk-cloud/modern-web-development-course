# Day 40 — Final Testing, Presentations, Viva, and Assessment

## Goal
Students complete final checks, present their live website, explain their code, and submit both project links.

## Learning outcomes
- Verify all required project features.
- Demonstrate the site on mobile and desktop.
- Explain HTML, CSS, and JavaScript files.
- Show the GitHub repository and live URL.
- Reflect on a challenge and improvement.

## 120-minute lesson
| Activity | Time |
|---|---:|
| Explain presentation order and assessment | 20 min |
| Recall required features and submission links | 4 min |
| Instructor models a short presentation | 30 min |
| Student final checks and presentations | 62 min |
| Record feedback and next steps | 4 min |
| **Total** | **120 min** |

## Presentation sequence
1. State the website purpose and intended audience.
2. Show Home, About, Services/Courses, and Contact.
3. Demonstrate working navigation and responsive layout.
4. Demonstrate both JavaScript interactions.
5. Show the GitHub repository and live website URL.
6. Explain one challenge and how it was solved.

Submit the GitHub repository URL and published website URL. Use the common [assessment rubric](../../assessments/assessment-rubrics.md).
