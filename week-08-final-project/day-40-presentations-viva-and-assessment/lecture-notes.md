# Day 40 Lecture Notes — Presentations and Assessment

## Presentation is evidence of understanding
A successful presentation shows what the website does and explains how the student built it. Students do not need advanced terminology. They should explain the main files in simple English and demonstrate working features.

## Final project requirements
- Home, About, Services or Courses, and Contact sections/pages.
- Working navigation.
- Readable CSS styling and responsive layout.
- Two simple JavaScript interactions.
- Working links and images.
- GitHub repository and live URL.
- Student presentation and explanation.

A single-page website with four sections can receive full credit. Separate HTML pages and extra effects are optional, not required.

## Suggested two-minute presentation
1. Introduce the website topic and audience.
2. Navigate through the four required sections.
3. Resize the browser to show responsive behaviour.
4. Demonstrate both JavaScript interactions.
5. Show the repository and published URL.
6. Explain one problem solved and one possible future improvement.

## Viva questions
- What is the role of the HTML file?
- Which CSS rule controls this layout?
- How did you make the page responsive?
- What event triggers your JavaScript feature?
- Where is your website hosted?

Use the published project rubric consistently. Assess understanding and required outcomes, not decorative complexity or expensive equipment. If a live internet issue prevents a demonstration, inspect saved evidence and arrange a fair retry.
