# Instructor Guide — Day 40

## Preparation
Review the common assessment rubric, arrange a fair presentation order, and test classroom display and internet access. Have a backup plan if connectivity fails.

## 120-minute plan
- 20 min: Explain order, timing, and criteria.
- 4 min: Recall required project features and submission links.
- 30 min: Model a concise presentation and viva.
- 62 min: Student final checks and presentations.
- 4 min: Record feedback and next steps.

## Model presentation
Show the four sections, working navigation, mobile layout, two JavaScript interactions, GitHub repository, and live URL. Explain one problem solved.

## Fairness
Use the same rubric for all students. Assess demonstrated understanding, not decorative complexity or expensive devices. If internet access fails, inspect saved evidence and arrange a fair retry. Never request passwords or tokens.
