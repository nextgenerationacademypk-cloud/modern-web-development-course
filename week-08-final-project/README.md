# Week 8 — Final Project and Presentation

## Goal

Bring the course skills together in a complete, responsive, published website.

## Final project choices

Students may create a website for:
- An academy or education centre
- A small business
- A personal portfolio
- A local service
- A fictional organisation

## Required pages or sections

- Home
- About
- Services or Courses
- Contact

These may be separate HTML pages or clearly organised sections, depending on the project plan.

## Required features

- Clear navigation
- Consistent HTML structure
- CSS styling and readable typography
- Responsive layout for mobile and desktop
- At least two simple JavaScript features
- Working links and images
- GitHub repository
- Published live website URL

Examples of JavaScript features include a mobile menu toggle, a simple form validation message, a FAQ show/hide control, a theme toggle, or a small calculator. A form does not need to send data to a server.

## Day-by-day plan

### Day 36 — Plan the project
- Choose a topic and audience.
- Draw a simple page layout on paper.
- List pages, sections, images, and interactive features.
- Create project folders and files.

### Day 37 — Build HTML
- Create page structure.
- Add navigation and content.
- Connect pages with working links.
- Check heading order and image alternative text.

### Day 38 — Style and make responsive
- Apply CSS and a consistent design.
- Use Flexbox or Grid where useful.
- Test mobile and desktop layouts.
- Tailwind may be used, but traditional CSS is fully acceptable.

### Day 39 — Add JavaScript and publish
- Add at least two simple interactive features.
- Test links, buttons, forms, and layout.
- Fix visible issues.
- Push the latest version to GitHub.
- Publish with GitHub Pages or another instructor-approved static hosting method.

### Day 40 — Present and evaluate
- Demonstrate the live website.
- Explain the HTML, CSS, and JavaScript features.
- Show the GitHub repository.
- Answer a few questions about the work.

## Student submission checklist

- [ ] Website has the required pages or sections.
- [ ] Navigation works.
- [ ] Layout works on mobile and desktop.
- [ ] At least two JavaScript features work.
- [ ] Images and links work.
- [ ] GitHub repository is accessible.
- [ ] Live website URL opens.
- [ ] Student can explain their own code.

## Expected result

Each student presents a working, responsive, multi-page website and explains how it was built.
