Apply consistent CSS, readable typography, spacing, Flexbox or Grid where useful, and mobile-first responsive checks.

## Required completion checklist

- [ ] Organise CSS into readable sections.
- [ ] Apply consistent colours, typography, spacing, and component styles.
- [ ] Use Flexbox or Grid for a suitable layout.
- [ ] Use a media query when the layout needs a breakpoint.
- [ ] Test the page at mobile and desktop widths.

## Troubleshooting

1. Read the exact browser or terminal message before changing code.
2. Check file names, folder location, spelling, and letter case.
3. Save the file and refresh the browser preview.
4. Test one change at a time.
5. Ask the instructor to review the smallest failing example if you are stuck.

## Optional challenge

Improve one small detail only after the required tasks are complete. Be ready to explain what you changed and why.

## Expected result

Your own project should show visible progress toward the final website. You should be able to explain the work rather than simply show copied code.
