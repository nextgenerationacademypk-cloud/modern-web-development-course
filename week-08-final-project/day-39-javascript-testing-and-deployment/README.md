# Day 39 — JavaScript, Testing, and Deployment

## Goal
Add two small interactions, test the website, push it to GitHub, and publish it with GitHub Pages.

## Learning outcomes
- Use familiar DOM selection and event listeners.
- Test each interaction separately.
- Inspect basic browser console errors.
- Commit and push the project safely.
- Publish a static website and verify the live URL.

## 120-minute lesson
| Activity | Time |
|---|---:|
| Explain scope, testing, and publishing | 20 min |
| Review DOM events and Git | 4 min |
| Instructor demo: interaction and Pages | 30 min |
| Student implementation, testing, and publishing | 62 min |
| Check repository and live URL | 4 min |
| **Total** | **120 min** |

## Practical checklist
1. Choose two interactions practised in Week 6.
2. Implement and test one interaction at a time.
3. Check keyboard access and button labels.
4. Use DevTools Console to inspect errors.
5. Check links, images, and mobile layout.
6. Review Git status, stage intended files, commit, and push.
7. Enable GitHub Pages for the correct branch and folder.
8. Open and test the live URL.

GitHub Pages hosts static files. A demo contact form can show a browser message but does not send or store a message. Never publish passwords, tokens, or private contact details.
