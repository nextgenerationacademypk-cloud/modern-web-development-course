# Instructor Guide — Day 39

## Goal
Students add two familiar interactions, test, push, and publish.

## Preparation
- Check student repositories and Git access.
- Review the starter JavaScript and GitHub Pages instructions.
- Prepare a small example of one click event and one accessible state change.
- Remind students that GitHub Pages is static hosting.

## 120-minute sequence
- **20 min:** Explain the two-feature limit, testing, Git, and static hosting.
- **4 min:** Recall DOM selection, event listeners, and commit sequence.
- **30 min:** Demonstrate one interaction, Console check, commit/push, and Pages setup.
- **62 min:** Students implement, test, push, and publish. Support one error at a time.
- **4 min:** Verify the repository and live URL.

## Questions
- What event starts this interaction?
- Which element changes?
- How did you test it?
- Does your form actually send data?
- Does the live URL show the latest commit?

## Checkpoint
Each student must show two working interactions, an accessible repository, and a live URL. If deployment is blocked by account or network issues, record evidence separately and allow a supervised retry; do not penalise students for infrastructure outside their control.

## Safety
Never ask for passwords or tokens. Do not put credentials in files. Check that public repositories contain no private contact data.
