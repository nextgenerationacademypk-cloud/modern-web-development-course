# Instructor Guide — Day 37: Build the HTML Structure and Content

## Teaching goal

Turn the approved plan into a semantic single-page website with four sections, working navigation, headings, text, and accessible images.

## Preparation

- Review the [Week 8 project brief](../README.md), [starter project](../../projects/final-project/starter/), and [assessment rubric](../../assessments/assessment-rubrics.md).
- Check the classroom computers, Chrome, VS Code, and student project folders.
- Prepare one small example. Avoid presenting a fully finished website for students to copy.
- Decide how students will submit their repository and live URL.

## Outcomes to observe

- Create semantic page regions using header, nav, main, section, and footer.
- Build four clearly identified content sections.
- Connect navigation links to section IDs.
- Use heading levels in a logical order.
- Add images with meaningful alternative text.

## 120-minute teaching sequence

### Explain semantic structure and project HTML checklist — 20 minutes

Explain the goal using a simple example. Connect today's work to the final project rubric.

### Recall section IDs and navigation links — 4 minutes

Ask short recall questions and correct misunderstandings before the practical.

### Instructor builds a simple page skeleton — 30 minutes

Start with <!doctype html>, html lang, head metadata, title, and body. Add header/nav, main, four section elements with unique IDs, and footer. Use anchor href values such as #about that exactly match section IDs. Add a local image with useful alt text.

### Students create and test their four-section HTML — 62 minutes

Circulate continuously. Ask students to explain what they are changing, check progress against the required checklist, and support learners without taking over their keyboard.

### Check structure, links, and image alternatives — 4 minutes

Ask short recall questions and correct misunderstandings before the practical.

## Demonstration notes

Start with <!doctype html>, html lang, head metadata, title, and body. Add header/nav, main, four section elements with unique IDs, and footer. Use anchor href values such as #about that exactly match section IDs. Add a local image with useful alt text.

## Questions to ask while circulating

- What are you trying to achieve with this part?
- Which file controls this behaviour or appearance?
- How will you test that it works?
- Can you explain this line in your own words?
- What is the smallest next step you can complete?

## Support and differentiation

For students who need help, reduce the task to one section or one visible feature at a time. Pair students for review, but require each student to understand and present their own work. For faster students, offer optional polish only after the required checklist is complete.

## Checkpoint / evidence

Check all four sections, section IDs, navigation targets, and image alternatives.

## Safety and fairness

- Do not ask for or accept passwords, tokens, or private account recovery information.
- Use fictional contact details and no real personal data in public projects.
- Give all students the same required scope and reasonable presentation time.
- Assess demonstrated learning, not expensive devices, internet speed, or decorative complexity.
- Do not award credit for features students cannot explain as their own work.
