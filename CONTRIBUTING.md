# Contributing

Thank you for helping improve this beginner web development course.

## Content standards

- Write in clear, simple English.
- Assume the reader has no programming experience.
- Explain the idea before showing code.
- Use small, complete examples that students can run.
- Include clear practical steps and an expected result.
- Keep the course achievable within 40 two-hour sessions.
- Do not add advanced frameworks or backend topics to the core course.

## Suggested lesson format

1. Lesson goals
2. Key words in simple language
3. Short explanation
4. Complete code example
5. Guided practical exercise
6. Independent student task
7. Homework
8. Quick review questions

## Changes

Keep file and folder names clear. Check code examples in a browser before suggesting them. Do not add private student information, passwords, API keys, exam answer keys, or confidential instructor notes to this public repository.
