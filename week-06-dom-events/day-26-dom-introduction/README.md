# Day 26 — DOM Introduction and Selecting Elements

**Week:** 6 | **Session:** 26 | **Duration:** 120 minutes

## Lesson purpose
Understand how JavaScript can find HTML elements and read or change simple page content.

## Learning outcomes
Students can explain the DOM, select an element by ID with getElementById(), select an element with querySelector(), read and change text using textContent, and link an external JavaScript file using defer.

## Prerequisites
Students can write a basic HTML page, link CSS, and use JavaScript variables, conditions, and functions from Week 5.

## Lesson sequence
- 20 min: Explain the DOM, document tree, and why webpages can change.
- 4 min: Quick theory review.
- 30 min: Demonstrate selecting a heading and paragraph; update text with a button.
- 62 min: Guided and independent exercises.
- 4 min: Practical review.

## Files
Open examples/index.html and examples/script.js in the same folder. Start Live Server from the HTML file.

## Required result
A page with a heading, paragraph, and button. When clicked, the button changes the paragraph text.

## Remember
JavaScript selects elements that already exist in the HTML. Keep the first examples to one or two elements.
