# Day 26 Homework — DOM Basics

## Task
Create a small page called **My DOM Practice**.

Your page must contain:
- One heading with ID page-title.
- Two paragraphs with different IDs.
- One button with ID update-button.
- A linked JavaScript file named script.js.

## JavaScript requirements
1. Select the heading by ID.
2. Select one paragraph with querySelector().
3. Change the heading text to your chosen page title.
4. When the button is clicked, change the second paragraph's text.

## Submit
- Your project folder or a screenshot showing the page.
- A screenshot of the JavaScript code.
- Write two sentences explaining what the DOM is and what textContent does.

## Marking guide — 5 marks
- Correct HTML elements and IDs: 1
- Correct JavaScript link: 1
- Correct selectors: 1
- Text update works: 1
- Explanation and neat work: 1

Use fictional content. Do not include passwords or private contact information.
