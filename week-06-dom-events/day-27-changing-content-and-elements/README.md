# Day 27 — Changing Content and Creating Elements

**Week:** 6 | **Session:** 27 | **Duration:** 120 minutes

## Purpose
Learn how JavaScript can update text, attributes, CSS classes, and add or remove simple page elements.

## Outcomes
Students can use textContent, setAttribute(), getAttribute(), classList.add()/remove()/toggle(), createElement(), appendChild(), and remove() in guided examples.

## 120-minute plan
20 min explanation; 4 min theory review; 30 min demonstration; 62 min practical work; 4 min review.

## Required result
A page with a button that changes a message and a button that adds a new list item. Students also practise removing an item.

## Learning links
- Required: [MDN — Node.textContent](https://developer.mozilla.org/en-US/docs/Web/API/Node/textContent)
- [MDN — Element.classList](https://developer.mozilla.org/en-US/docs/Web/API/Element/classList)
- [MDN — Document.createElement()](https://developer.mozilla.org/en-US/docs/Web/API/Document/createElement)
- [MDN — Element.append()](https://developer.mozilla.org/en-US/docs/Web/API/Element/append)

## Safety note
Use textContent when adding text supplied by a user. Do not build HTML strings from user input or use innerHTML for this lesson.
