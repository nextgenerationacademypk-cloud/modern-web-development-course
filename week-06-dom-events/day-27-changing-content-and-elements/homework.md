# Day 27 Homework — Dynamic List

## Task
Create a page with a heading, an unordered list, and an Add Item button.

## Requirements
- Use JavaScript to create a new li element.
- Set its text with textContent.
- Append it to the list.
- Add a CSS class to at least one element with classList.
- Add a way to remove an item.

## Submit
A screenshot of the page before and after adding an item, plus your JavaScript file.

## Marking — 5 marks
- Correct element selection: 1
- Creates a list item: 1
- Sets text and appends it: 1
- Removes an item: 1
- Clear code and explanation: 1

Do not use innerHTML to insert text entered by a user.
