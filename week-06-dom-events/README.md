# Week 6 — DOM Manipulation and JavaScript Events

**Sessions:** 26–30 | **Duration:** 10 hours | **Level:** Absolute beginner

## Week goal
Learn how JavaScript can read and update a webpage after it loads. Practise selecting elements, changing text and attributes, creating and removing elements, responding to user actions, and checking simple form input.

## Daily lessons
1. [Day 26 — DOM Introduction and Selecting Elements](day-26-dom-introduction/README.md)
2. [Day 27 — Changing Content and Creating Elements](day-27-changing-content-and-elements/README.md)
3. [Day 28 — Events and Event Listeners](day-28-events-and-event-listeners/README.md)
4. [Day 29 — Forms and Basic Validation](day-29-forms-and-validation/README.md)
5. [Day 30 — Guided To-Do List Project](day-30-todo-list-project/README.md)

## Learning outcomes
Students can explain the DOM, select elements with getElementById() and querySelector(), update text and attributes, use CSS classes, create and remove elements, attach click/input/submit event listeners, use preventDefault(), and build a small To-Do List app.

## Required tools
VS Code, Chrome, and Live Server. Continue using HTML, CSS, and JavaScript files. No library, framework, server, database, or build tool is required.

## Standard class structure
20 min explanation, 4 min theory review, 30 min instructor demonstration/guided coding, 62 min student practice, 4 min practical review.

## Scope boundaries
Use plain JavaScript and the browser DOM. Do not introduce React, APIs, asynchronous programming, modules, classes, or complex state management. The To-Do List stores tasks only while the page remains open. localStorage is optional future learning, not required.

## Important safety and accuracy notes
- Use textContent for student-entered text; do not teach innerHTML for inserting user input.
- Client-side validation improves user experience but does not replace server-side validation.
- The sample form does not send or store information.
- Use fictional tasks and sample details in demonstrations.

## Week completion check
Each student demonstrates selecting an element, changing its text, responding to a button click, and completing the To-Do List core task: add a non-empty task, display it, and delete it.
