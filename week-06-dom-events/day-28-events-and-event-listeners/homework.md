# Day 28 Homework — Interactive Counter

## Task
Build a counter page with:
- A number display starting at zero.
- Increase, Decrease, and Reset buttons.
- A text input and a paragraph showing a live preview.

## Requirements
- Use addEventListener() for each button.
- Use the input event for the live preview.
- Do not allow the counter to become negative.
- Keep the JavaScript in script.js.

## Submit
A screenshot of the working page and the JavaScript file.

## Marking — 5 marks
- Three working counter controls: 2
- Live input preview: 1
- Correct event listeners: 1
- Clear code and explanation: 1
