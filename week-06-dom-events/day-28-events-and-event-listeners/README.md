# Day 28 — Events and Event Listeners

**Week:** 6 | **Session:** 28 | **Duration:** 120 minutes

## Purpose
Understand how a webpage responds to user actions with JavaScript event listeners.

## Outcomes
Students can explain an event, attach a click listener, read a simple input value, respond to input changes, and use a named callback function.

## 120-minute plan
20 min explanation; 4 min review; 30 min demo; 62 min practical; 4 min review.

## Required result
A counter with Increase and Reset buttons, plus a live text preview that updates as the user types.

## Learning links
- Required: [MDN — Introduction to events](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/Events)
- [MDN — addEventListener()](https://developer.mozilla.org/en-US/docs/Web/API/EventTarget/addEventListener)
- [MDN — Event reference](https://developer.mozilla.org/en-US/docs/Web/Events)

## Scope
Use click and input events only as the main focus. Submit events are introduced for the next lesson. Avoid event bubbling, delegation, keyboard event complexity, and custom events.
