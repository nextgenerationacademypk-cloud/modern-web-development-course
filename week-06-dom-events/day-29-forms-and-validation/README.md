# Day 29 — Forms and Basic Validation

**Week:** 6 | **Session:** 29 | **Duration:** 120 minutes

## Purpose
Handle a simple form in the browser, check required input, and show helpful feedback without sending data to a server.

## Outcomes
Students can select a form, listen for submit, use preventDefault(), read input values, trim extra spaces, check empty values, and display a text message.

## 120-minute plan
20 min explanation; 4 min review; 30 min demo; 62 min practical; 4 min review.

## Required result
A small task-entry form that refuses empty or whitespace-only text and displays a success or error message.

## Learning links
- Required: [MDN — Your first form](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Your_first_form)
- [MDN — Submit event](https://developer.mozilla.org/en-US/docs/Web/API/HTMLFormElement/submit_event)
- [MDN — String.trim()](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/trim)
- [MDN — Constraint validation](https://developer.mozilla.org/en-US/docs/Web/HTML/Constraint_validation)

## Safety and scope
This is a client-side classroom demonstration. It does not send, store, or protect information. Do not collect passwords, phone numbers, or private student information. HTML required attributes and JavaScript checks help users but cannot replace server-side validation in a real application.
