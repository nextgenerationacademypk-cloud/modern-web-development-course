# Final Project Assessment

**Suggested marks:** 30

## Project
Build and publish a responsive multi-page website for an academy, business, service, or personal portfolio.

## Required features
- Home, About, Services or Courses, and Contact pages or sections
- Working navigation
- HTML5 structure
- CSS styling and responsive layout
- At least two JavaScript features
- Working links and images
- GitHub repository
- Live website URL
- Student presentation

## Marking rubric

| Area | Marks |
|---|---:|
| HTML structure and content | 5 |
| CSS styling and layout | 5 |
| Responsive behaviour | 5 |
| JavaScript features | 5 |
| Navigation and usability | 3 |
| GitHub repository and live deployment | 4 |
| Presentation and explanation | 3 |
| **Total** | **30** |

## Student presentation
1. Introduce the website and its intended audience.
2. Open the live website.
3. Demonstrate navigation and interactive features.
4. Show the GitHub repository.
5. Explain one HTML feature, one CSS feature, and one JavaScript feature.
6. Describe one problem solved while building the project.

## Submission checklist
- [ ] Project files are complete.
- [ ] Links and images work.
- [ ] Mobile and desktop layouts have been checked.
- [ ] At least two JavaScript features work.
- [ ] GitHub repository link is submitted.
- [ ] Live website URL is submitted.
- [ ] Student can explain the code.

Tailwind CSS is optional for this project. Traditional CSS is acceptable.
