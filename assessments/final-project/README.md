# Final Project Assessment

**Suggested marks:** 30

## Project

Build and publish a responsive website for an academy, business, service, or personal portfolio.

For the required level, students may create one page with four clear sections: Home, About, Services or Courses, and Contact. Separate HTML pages are an optional extension. The instructor should provide a simple starter structure and demonstrate the two JavaScript patterns students will use.

## Required features

- Four required content sections or equivalent pages
- Working navigation
- HTML5 structure and meaningful content
- CSS styling and responsive layout
- Two simple JavaScript interactions based on patterns taught in class
- Working links and images
- GitHub repository
- Live website URL
- Student presentation

## Marking rubric

| Area | Marks |
|---|---:|
| HTML structure and content | 5 |
| CSS styling and layout | 5 |
| Responsive behaviour | 5 |
| JavaScript interactions | 5 |
| Navigation and usability | 3 |
| GitHub repository and live deployment | 4 |
| Presentation and explanation | 3 |
| **Total** | **30** |

For JavaScript, full marks require two working interactions that the student can explain. Award partial marks for one working interaction or two partly working interactions. Do not require advanced JavaScript beyond the course.

## Student presentation

1. Introduce the website and its intended audience.
2. Open the live website.
3. Demonstrate the navigation and two interactive features.
4. Show the GitHub repository.
5. Explain one HTML feature, one CSS feature, and one JavaScript feature.
6. Describe one problem solved while building the project.

## Submission checklist

- [ ] Required sections or pages are present.
- [ ] Navigation works.
- [ ] Mobile and desktop layouts have been checked.
- [ ] Two simple JavaScript interactions work.
- [ ] Images and links work.
- [ ] GitHub repository link is submitted.
- [ ] Live website URL is submitted.
- [ ] Student can explain the code.

Tailwind CSS is optional. Traditional CSS is fully acceptable. A single-page project can receive full marks when it meets the required criteria; multiple pages are not required for full marks.
