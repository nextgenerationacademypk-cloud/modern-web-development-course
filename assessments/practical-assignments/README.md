# Practical Assignment Guide

Each weekly assignment should be small, clearly explained, and connected to the current lesson.

## Suggested weekly submissions
1. Week 1: first webpage with heading, introduction, and interests.
2. Week 2: semantic profile page with links, image, list, and form.
3. Week 3: styled academy information page using external CSS.
4. Week 4: responsive landing page tested at three screen widths.
5. Week 5: calculator with four arithmetic operations.
6. Week 6: to-do list with add and remove features.
7. Week 7: GitHub repository link, Tailwind practice card, and published static page.
8. Week 8: final project and presentation.

## General marking ideas
Check whether the work runs, meets the task requirements, is organised, and can be explained by the student. Give feedback that identifies one strength and one practical next improvement.
