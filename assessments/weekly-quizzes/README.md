# Weekly Quiz Guide

Use a short quiz at the end of each week. A suggested format is five questions mixing definitions, code reading, and practical reasoning.

| Week | Quiz topics |
|---|---|
| 1 | Web, browser, URL, files, folders, HTML basics |
| 2 | HTML elements, attributes, links, images, lists, forms, semantics |
| 3 | CSS selectors, external stylesheets, box model, Flexbox |
| 4 | Responsive design, mobile-first, media queries, Grid |
| 5 | Variables, data types, operators, conditions, functions, arrays, loops |
| 6 | DOM selection, events, input values, element creation |
| 7 | Git, commits, GitHub, Tailwind utilities, GitHub Pages |
| 8 | Project structure, testing, accessibility basics, explaining code |

The instructor should create and keep answer keys privately. Do not place unreleased answers in this public folder.
