# Assessments

Assessment checks both practical ability and understanding.

## Assessment components
- Weekly practical work: 30 marks
- Homework: 15 marks
- Mid-course practical exam: 15 marks
- Final project: 30 marks
- Theory and viva: 10 marks

See [Assessment Policy](../course-outline/assessment-policy.md) for completion requirements and [Assessment Rubrics](assessment-rubrics.md) for the marking criteria.

## Student preparation
- Review the weekly lesson notes.
- Practise without copying a finished solution.
- Make sure you can explain the code you submit.
- Test your work in a browser.
- Keep your project files organised.

## Instructor note
This is a public student repository. Do not publish confidential answer keys, private marking notes, or unreleased exam solutions here. Keep those in a separate private instructor repository.
