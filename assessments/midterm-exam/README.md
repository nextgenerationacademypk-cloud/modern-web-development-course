# Mid-Course Practical Exam

**Suggested timing:** End of Week 4  
**Suggested marks:** 15

## Purpose
Check that students can create an HTML page and style it with CSS before moving into JavaScript.

## Suggested task
Create a small responsive information page for a fictional club, academy, or service.

## Required features
- Correct basic HTML document structure
- Heading and paragraphs
- Navigation links
- At least two content sections
- External CSS file
- Consistent colours and spacing
- A simple Flexbox or Grid layout
- A media query that improves the mobile layout

## Marking guide

| Area | Marks |
|---|---:|
| HTML structure and content | 4 |
| CSS connection and styling | 4 |
| Layout and spacing | 3 |
| Responsive behaviour | 3 |
| Student explanation | 1 |
| **Total** | **15** |

## Instructor note
Set the exact time limit and submission rules before the exam. Keep the answer key and any model solution private.
