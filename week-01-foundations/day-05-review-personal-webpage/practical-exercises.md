# Day 5 Mini Project — My Personal Introduction Page

**Student name:** ____________________  
**Date:** ____________________

## Project goal

Create a simple webpage that introduces you to a visitor. Use the HTML skills from this week.

You may use a fictional name and fictional details. Do not include private contact information.

## Step 1 — Plan your content

Write short notes before coding.

- Page title: __________________________________________
- Main heading: ________________________________________
- Introduction: ________________________________________
- Interests or hobbies: _________________________________
- What I want to learn: _________________________________

## Step 2 — Open your project

1. Open VS Code.
2. Open your `my-first-website` folder.
3. Open `index.html`.

## Step 3 — Build your page

Use this starter structure and replace the sample text with your own words.

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My Personal Page</title>
</head>
<body>
  <h1>Welcome to My Page</h1>

  <p>Write a short introduction here.</p>

  <p>Write about your interests or hobbies here.</p>

  <p>Write what you want to learn here.</p>
</body>
</html>
```

## Step 4 — Save and preview

1. Save `index.html`.
2. Open it in your browser or use Live Server if available.
3. Read the page.
4. Return to VS Code and correct any mistakes.
5. Save and preview again.

## Step 5 — Show your work

Be ready to show the instructor:

- Your project folder
- Your `index.html` file
- Your page in the browser

Explain which part of the code creates the title, heading, and paragraphs.

## Project checklist

- [ ] Correct HTML document structure
- [ ] Meaningful page title
- [ ] One main heading
- [ ] Three paragraphs
- [ ] File saved in the project folder
- [ ] Page opens in a browser
- [ ] No private contact details included
