# Day 5 — Week 1 Review and Personal Webpage

**Week:** 1 of 8 · **Session:** 2 hours · **Level:** Absolute beginner

## Lesson goal

Review the web, project files, basic HTML, and browser preview. Use these skills to build a simple personal introduction webpage.

## Learning outcomes

By the end of this lesson, students can:

1. Explain the basic meaning of internet, web, website, webpage, browser, and URL.
2. Find their project folder and open it in VS Code.
3. Create and edit a basic HTML document.
4. Preview a webpage in a browser.
5. Build a simple personal introduction page with a title, heading, and paragraphs.
6. Explain the basic steps they used to create the page.

## Mini project — My Personal Introduction Page

Create one HTML page that introduces you. It must include:

- A meaningful page title
- One main heading
- A short introduction paragraph
- A paragraph about interests or hobbies
- A paragraph about what you want to learn

Students may use a fictional name and fictional details. Do not include private contact details or sensitive personal information.

## Expected result

A saved `index.html` file that opens correctly in a browser and contains the required personal introduction content.

## Week 1 checkpoint

Students should be able to create, save, open, and edit a basic webpage. Students who need more practice should receive support before moving to more HTML elements in Week 2.
