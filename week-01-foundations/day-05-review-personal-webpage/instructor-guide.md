# Day 5 Instructor Guide — Week 1 Review and Personal Webpage

## Teaching purpose

Consolidate the first four lessons and give every student a small achievement: a personal introduction webpage. Assess basic readiness for Week 2 HTML lessons.

## Preparation checklist

- [ ] Check that students can open VS Code and their project folders.
- [ ] Prepare the example personal page.
- [ ] Open the wireframe and workflow diagrams.
- [ ] Test the example in the classroom browser.
- [ ] Prepare a backup HTML file.
- [ ] Remind students not to include private personal information.

## Two-hour lesson plan

### 1. Review the week — 20 minutes

Use short questions to revisit:

- Internet and web
- Website and webpage
- Browser and URL
- Files, folders, and file extensions
- VS Code
- HTML tags and elements
- Head and body
- Save and preview

Ask students to explain ideas in simple English. Correct misunderstandings before the project begins.

### 2. Quick review — 4 minutes

Ask four quick questions:

1. What does HTML do?
2. Which file are we editing?
3. Where does visible page content go?
4. How do we see the page in a browser?

### 3. Instructor project demonstration — 30 minutes

**A. Show the target layout (5 minutes)**

Display the personal page wireframe. Explain the required content.

**B. Plan the content (5 minutes)**

Write a sample title, heading, and three short paragraphs on the board. Use fictional details.

**C. Build the page (12 minutes)**

Type the basic HTML structure and add the content. Explain each section as you work.

**D. Save and preview (5 minutes)**

Save the file and open it in a browser. Make one small change and show the updated result.

**E. Explain the result (3 minutes)**

Point out the title, heading, and paragraphs. Remind students not to include private contact information.

### 4. Student project work — 62 minutes

- Plan page content: 8 minutes
- Build HTML document: 22 minutes
- Add and improve the text: 10 minutes
- Save and preview: 10 minutes
- Fix mistakes and check requirements: 8 minutes
- Prepare a short explanation: 4 minutes

Support students who are still learning to type tags. Do not add CSS or advanced HTML elements to this project.

### 5. Project review — 4 minutes

Check each student's page quickly. Ask the student to identify the HTML file and explain how they previewed it.

## Simple project assessment — 10 marks

| Requirement | Marks |
|---|---:|
| Correct basic HTML document structure | 2 |
| Meaningful page title and one main heading | 2 |
| Three relevant paragraphs | 2 |
| File saved in the correct project folder | 2 |
| Page opens and displays in a browser | 2 |
| **Total** | **10** |

This is a Week 1 learning check, not the course final assessment.

## Common problems

| Problem | Instructor response |
|---|---|
| Student cannot find the project | Help them locate the folder before editing |
| HTML structure is incomplete | Compare with the starter example |
| Content is placed in the head | Move visible content into the body |
| Browser shows old content | Save and refresh the correct page |
| Student includes private details | Ask them to replace them with safe, general information |

## Week 1 readiness checklist

- [ ] Student can find a project folder.
- [ ] Student can open a folder in VS Code.
- [ ] Student can create and save an HTML file.
- [ ] Student can identify head and body.
- [ ] Student can use a heading and paragraph.
- [ ] Student can preview the page in a browser.

## Planning support for Week 2

Students who need help should receive short practice with opening files, saving, and identifying HTML tags. Do not move faster just to finish the schedule. A strong foundation matters more than speed.
