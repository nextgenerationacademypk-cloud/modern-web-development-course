# Day 5 Homework — Improve Your Personal Page

## Task

Review the personal introduction page you created in class.

Make these improvements:

1. Check the spelling in your page title and paragraphs.
2. Make sure your main heading is clear.
3. Make sure all visible content is inside the body.
4. Add one more paragraph about a learning goal or a project you hope to build.
5. Save your file and preview it in a browser.

Do not add CSS or JavaScript yet. We will learn more HTML elements in Week 2.

## Week 1 reflection

Write one or two sentences for each question.

1. What is one new thing you learned about the web?
2. What is the purpose of HTML?
3. What is the difference between VS Code and a browser?
4. Which skill do you want to practise more?
