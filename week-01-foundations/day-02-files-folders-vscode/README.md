# Day 2 — Files, Folders, File Extensions, and VS Code

**Week:** 1 of 8 · **Session:** 2 hours · **Level:** Absolute beginner

## Lesson goal

Learn how to organise website files and folders, recognise common file extensions, and use Visual Studio Code to open a project.

## Learning outcomes

By the end of this lesson, students can:

1. Explain the difference between a file and a folder.
2. Recognise common file extensions such as `.html`, `.css`, `.js`, and `.txt`.
3. Create and name a project folder.
4. Open a folder in Visual Studio Code.
5. Create and save a file named `index.html`.
