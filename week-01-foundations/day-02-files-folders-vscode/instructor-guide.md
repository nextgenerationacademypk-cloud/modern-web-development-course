# Day 2 Instructor Guide — Files, Folders, and VS Code

## Teaching purpose

Help students become comfortable with basic file management and opening a project in VS Code. Some students may be unfamiliar with creating folders. Demonstrate slowly and allow time for practice.

## Preparation checklist

- [ ] Install VS Code on classroom computers before class.
- [ ] Check that students can open the file manager.
- [ ] Prepare a sample folder named `demo-website`.
- [ ] Prepare a real screenshot of the VS Code interface installed in the classroom.
- [ ] Test the projector.
- [ ] Keep the Day 2 folder diagram and file-extension diagram ready.

## Two-hour lesson plan

### 1. Explain files and folders — 20 minutes

Explain:

- A file stores information.
- A folder organises files.
- A project folder keeps website files together.
- A file extension helps identify the type of file.
- Introduce HTML, CSS, JavaScript, text, and image extensions.

Show [the project folder diagram](images/project-folder-tree.svg) and [the file extension diagram](images/file-name-extension.svg).

### 2. Quick review — 4 minutes

Ask:

1. What is a webpage?
2. Which application opens websites?
3. What is a URL?
4. What is one example of a browser?

### 3. Instructor demonstration — 30 minutes

**A. Create a folder (8 minutes)**

1. Open the file manager.
2. Navigate to Documents or another suitable location.
3. Create `demo-website`.
4. Explain where the folder is saved.

**B. Open VS Code (7 minutes)**

1. Start VS Code.
2. Point out the Activity Bar, Explorer, Editor, tabs, and Status Bar.
3. Use a real screenshot from the classroom installation as a visual reference.
4. Choose File → Open Folder and open `demo-website`.

**C. Create and save a file (10 minutes)**

1. Use the Explorer's New File control.
2. Create `index.html`.
3. Explain why the extension matters.
4. Save the file.

**D. Review the folder (5 minutes)**

Show the project folder in VS Code and the computer's file manager. Explain that both are showing the same project files.

### 4. Student practical work — 62 minutes

- Create a project folder: 10 minutes
- Open the folder in VS Code: 10 minutes
- Create `index.html`: 10 minutes
- Check the name and extension: 10 minutes
- Recreate the folder structure independently: 12 minutes
- Help a partner check the result: 10 minutes

Walk around and check each student's folder and file name.

### 5. Practical review — 4 minutes

Ask students to show:

- Their project folder
- The `index.html` file in VS Code
- The same file in the file manager

## Common problems

| Problem | Help |
|---|---|
| Student creates a file in the wrong folder. | Reopen the correct project folder in VS Code. |
| File is named `index.html.txt`. | Show file extensions and rename carefully. |
| Student opens only a file, not the project folder. | Demonstrate File → Open Folder. |
| Student cannot find Explorer. | Select the Explorer icon in the Activity Bar or use the View menu. |
| VS Code is not installed. | Use a prepared classroom computer while installation is arranged. |

## End-of-class checklist

- [ ] Each student has a project folder.
- [ ] Each student can open the folder in VS Code.
- [ ] Each student has an `index.html` file.
- [ ] Students can explain a file extension.
- [ ] Students know where their project is saved.

## Important

Do not begin detailed HTML teaching today. The goal is file organisation and editor familiarity. Day 3 introduces the HTML document.
