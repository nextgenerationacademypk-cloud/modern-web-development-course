## Activity 3 — Create your project folder

1. Open the file manager.
2. Go to Documents or a location approved by your instructor.
3. Create a folder named `my-first-website`.
4. Open VS Code.
5. Choose File → Open Folder.
6. Select your `my-first-website` folder.

Ask your instructor to check the folder before continuing.

## Activity 4 — Create index.html

1. Find the Explorer panel in VS Code.
2. Create a new file.
3. Name it exactly `index.html`.
4. Save the file.
5. Check that it appears inside `my-first-website`.

Your expected folder structure:

```text
my-first-website/
└── index.html
```

## Activity 5 — Independent challenge

Close the project folder in VS Code. Open VS Code again and independently reopen your `my-first-website` folder.

Show your partner:
