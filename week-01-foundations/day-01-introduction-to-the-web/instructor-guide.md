# Day 1 Instructor Guide — Introduction to the Web

## Teaching purpose

This is the students' first lesson. Build confidence and curiosity. Use familiar websites and simple examples. Avoid deep technical explanations and avoid asking students to memorise long definitions.

## Preparation checklist

Before class:

- [ ] Check that the instructor computer can connect to the internet.
- [ ] Open a browser and prepare two or three familiar, safe websites.
- [ ] Prepare a simple example URL: `https://www.example.com/about`.
- [ ] Test the projector or shared screen.
- [ ] Make sure students can use a browser on their computers.
- [ ] Open the Day 1 lecture notes and observation activity.

If a student does not have a computer, pair them with another student for the practical activity.

## Two-hour teaching plan

### 1. Introduce the topic — 20 minutes

**Explain (20 minutes):**

- Ask: "Which websites do you use?"
- Explain the internet and the web using simple examples.
- Explain website versus webpage.
- Introduce browser, web server, and URL.
- Explain the browser-to-server process in five simple steps.
- Briefly introduce front end and back end.

**Teaching tip:** Do not spend time on network protocols, DNS, hosting types, IP addresses, or server configuration. These are outside today's beginner lesson.

### 2. Quick review — 4 minutes

Ask four short questions:

1. What do we use to open a website?
2. What is one webpage on an academy website?
3. Where do you type a website address?
4. Is the internet exactly the same as the web?

Accept short answers. Correct misunderstandings kindly.

### 3. Instructor demonstration — 30 minutes

Share your browser screen.

**Demonstration A: Browser controls (10 minutes)**

1. Open the browser.
2. Point to the tab and address bar.
3. Use Back and Forward.
4. Refresh the page.
5. Open a second tab.
6. Explain the page area.

**Demonstration B: Reading a URL (8 minutes)**

1. Enter `https://www.example.com/about`.
2. Point out `https`, the domain, and the path.
3. Explain that a URL is an address.
4. Do not teach advanced URL rules.

**Demonstration C: Website sections (8 minutes)**

Open a simple website. Identify its header, navigation, main content, and footer where present. Explain that layouts differ from site to site.

**Demonstration D: Request and response (4 minutes)**

Draw this simple flow on the board:

`Student → Browser → Internet → Web server → Browser displays page`

Explain that the browser requests content and the server responds. Keep it conceptual.

### 4. Student practical activities — 62 minutes

Students complete the activities in [practical-exercises.md](practical-exercises.md).

Suggested use of time:

- Activity 1 — Browser exploration: 12 minutes
- Activity 2 — Read a URL: 10 minutes
- Activity 3 — Find webpage sections: 15 minutes
- Activity 4 — Compare two websites: 20 minutes
- Write a short explanation: 5 minutes

Walk around the room. Help students who are unfamiliar with tabs, address bars, or navigation buttons. Ask students to explain what they found rather than copying definitions.

### 5. Practical review and exit check — 4 minutes

Ask each student to complete these sentences:

- "A browser is ..."
- "A URL is ..."
- "A web server ..."
- "When I enter a URL, ..."

Collect or check their observation sheets. Note students who need extra support in the next class.

## Questions to ask during class

- What is the difference between a website and a webpage?
- Which part of the browser shows the URL?
- Why might a website have a navigation menu?
- What do you see in the footer of this website?
- What does the browser ask the server for?

## Common beginner misunderstandings

| Misunderstanding | Simple correction |
|---|---|
| Internet and web mean exactly the same thing. | The web is one service that uses the internet. |
| A website and a webpage are the same. | A website can contain many webpages. |
| Google Search is the browser. | Google Search is a search service; Chrome and Edge are browsers. |
| The URL is the page title. | The URL is the web address shown in the address bar. |
| Every website has the same layout. | Websites can have different layouts and sections. |
| The browser and server are the same thing. | The browser requests content; a web server provides it. |

## Teaching quality reminders

- Use simple English and explain one new word at a time.
- Demonstrate first, then let students practise.
- Do not rush students who are new to computers.
- Do not introduce HTML tags in detail today.
- Praise careful observation and questions.
- Keep the practical work as the main part of the lesson.

## End-of-class instructor checklist

- [ ] Students can identify the browser address bar.
- [ ] Students can explain website versus webpage.
- [ ] Students can recognise a basic URL.
- [ ] Students can identify common webpage sections.
- [ ] Students completed the observation activity.
- [ ] Homework has been explained.
