# Day 1 — Introduction to the Web

**Course:** Modern Web Development — Complete Beginner to Practical Developer  
**Week:** 1 of 8  
**Session length:** 2 hours (120 minutes)  
**Level:** Absolute beginner

## Lesson goal

Understand what the web is, recognise the main parts of a website and a browser, and explain in simple words how a browser displays a webpage.

## Learning outcomes

By the end of this lesson, students can:

1. Explain the difference between the internet and the World Wide Web.
2. Identify a website, webpage, browser, web server, and URL.
3. Find the main parts of a browser window.
4. Identify common sections of a webpage.
5. Describe a simple browser-to-server request.
6. Compare two websites using a short observation checklist.

## Visual learning materials

This lesson includes four original diagrams: internet and web, browser parts, webpage layout, and browser request-and-response flow. They are included in the notes and activities below.

## What students need

- A computer with a working web browser, preferably Google Chrome
- Internet access
- Notebook and pen
- Projector or shared screen for instructor demonstrations

No coding experience is needed today. Students will start creating files and writing HTML in the next lessons.

## Two-hour session plan

| Part | Time |
|---|---:|
| Short explanation and new concepts | 20 minutes |
| Quick review questions | 4 minutes |
| Instructor browser demonstration | 30 minutes |
| Student observation and comparison activities | 62 minutes |
| Practical review and exit check | 4 minutes |
| **Total** | **120 minutes** |

## Practical result

Each student completes the website observation sheet, identifies browser controls and webpage sections, and explains the basic path from entering a URL to seeing a page.
