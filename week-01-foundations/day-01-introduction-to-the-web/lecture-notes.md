# Day 1 Lecture Notes — Introduction to the Web

## 1. What is the internet?

The **internet** is a worldwide network that connects computers, phones, servers, and other devices. These devices can send and receive information.

Examples of things people use through the internet:

- Websites
- Email
- Online video
- Online games
- File sharing
- Video calls

The internet is the network. It supports many different services.

## 2. What is the World Wide Web?

The **World Wide Web**, usually called **the web**, is a service that lets people open and use connected pages of information through a web browser.

A website is one part of the many services that use the internet.

**Remember:** The internet and the web are related, but they do not mean exactly the same thing.

## 3. What is a website?

A **website** is a group of related webpages that are usually available under one domain name.

Examples:

- An academy website can show its courses, teachers, and contact details.
- A news website can show news stories.
- A shop website can show products and prices.

A website can have many pages connected by links and a navigation menu.

## 4. What is a webpage?

A **webpage** is one page that you can open in a browser.

For example, a website may have:

- Home page
- About page
- Courses page
- Contact page

A webpage can contain text, images, links, buttons, videos, and forms.

## 5. What is a web browser?

A **web browser** is an application used to open and view websites.

Examples include:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari

A browser helps you enter a web address, request a page, and display the result.

## 6. What is a web server?

A **web server** is a computer and software that stores or provides website files and responds to requests from browsers.

A simple example:

1. You enter a website address in your browser.
2. Your browser sends a request over the internet.
3. A web server receives the request.
4. The server sends back the files or information needed for the page.
5. Your browser displays the webpage.

This is a simplified explanation. Real websites can involve more steps and services.

## 7. What is a URL?

**URL** means **Uniform Resource Locator**. It is the web address used to locate a resource, such as a webpage.

Example:

`https://www.example.com/about`

Common parts:

- `https` — the scheme or protocol used for the connection.
- `www.example.com` — the domain name.
- `/about` — the path to a page or resource.

Do not worry about advanced URL details today. Learn to recognise the address bar and read a basic web address.

## 8. Main parts of a browser window

Find these parts in your browser:

- **Tab:** lets you keep more than one page open in the same window.
- **Address bar:** shows the current URL and lets you enter another one.
- **Back button:** returns to the previous page in the current tab.
- **Forward button:** moves forward after you have used Back.
- **Refresh button:** asks the browser to load the current page again.
- **Bookmark:** saves a page so you can find it later.
- **Page area:** the main area where website content appears.

Browser designs can look a little different. The main ideas are the same.

## 9. Common sections of a webpage

Many websites use some of these sections:

- **Header:** the top area, often containing a logo or website name.
- **Navigation:** links that help visitors move between pages or sections.
- **Main content:** the most important information on the page.
- **Sidebar:** extra information shown beside the main content on some websites.
- **Footer:** the bottom area, often containing contact details, copyright information, or useful links.

Not every website uses all these sections.

## 10. Front end and back end — a first look

- **Front end:** the part of a website that visitors see and use in their browser.
- **Back end:** the server-side part that handles tasks such as processing information and working with data.

In this course, we begin with front-end development: HTML, CSS, and JavaScript.

You do not need to learn back-end programming in this lesson.

## 11. What is web development?

**Web development** means creating and maintaining websites and web applications.

The main front-end technologies in this course are:

- **HTML:** gives webpage content its structure.
- **CSS:** controls how webpage content looks.
- **JavaScript:** adds actions and interactive behaviour.

We will study these technologies step by step. Today is about understanding the web, not memorising code.
