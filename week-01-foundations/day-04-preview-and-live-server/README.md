# Day 4 — Preview Your Webpage and Use Live Server

**Week:** 1 of 8 · **Session:** 2 hours · **Level:** Absolute beginner

## Lesson goal

Open an HTML file in a browser, understand the relationship between the editor and browser, and use the VS Code Live Server extension if it is installed.

## Learning outcomes

By the end of this lesson, students can:

1. Open a saved HTML file in a browser.
2. Explain that the browser displays the saved HTML document.
3. Make a change in VS Code and save it.
4. Refresh the browser to see the saved change.
5. Use Live Server to preview a page when the extension is available.
6. Identify simple problems such as an unsaved file or an incorrect file path.
