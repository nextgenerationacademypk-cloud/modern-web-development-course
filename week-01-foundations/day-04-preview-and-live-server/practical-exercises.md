## Activity 4 — Try Live Server

If Live Server is installed:

1. Open your project folder in VS Code.
2. Open `index.html`.
3. Select Go Live.
4. Check that your browser opens the page.
5. Change one sentence and save.
6. Check the browser for the update.

If Live Server is not available, repeat Activity 2 using the direct file-opening method.

## Activity 5 — Independent challenge

Change the page title, heading, and paragraph. Save your work and show the updated result in your browser.

## Troubleshooting checklist

If your page does not update:

- [ ] Did I save the file?
- [ ] Did I refresh the correct browser tab?
- [ ] Am I editing the same file that is open in the browser?
- [ ] Is the file named `index.html`?

## Final checklist

- [ ] I opened my page in a browser.
- [ ] I changed the heading.
- [ ] I saved and refreshed.
- [ ] I changed a paragraph.
- [ ] I tried Live Server or used direct file preview.
