# Day 4 Homework — Improve and Preview Your Page

## Task

Open your personal HTML page and make these changes:

1. Change the page title to a meaningful title.
2. Write a new main heading.
3. Add one new paragraph about your interests or learning goals.
4. Save your file.
5. Open the page in a browser and check the result.

Use Live Server if it is available on your computer. Otherwise, open the HTML file directly in your browser.

## Write short answers

1. What is the difference between VS Code and a browser?
2. Why should you save before refreshing?
3. What does Live Server help you do?
4. Is a local preview the same as publishing a website?

## Submission checklist

- [ ] I updated the title.
- [ ] I updated the heading.
- [ ] I added a paragraph.
- [ ] I saved the file.
- [ ] I checked the page in a browser.
- [ ] I answered the four questions.
