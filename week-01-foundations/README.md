# Week 1 — Web Foundations and Your First Webpage

## Goal

Understand the basic idea of the web, prepare your computer, and create your first HTML page.

## Day-by-day lessons

### Day 1 — What is the web?
- Learn the meaning of website, webpage, browser, web server, internet, and URL.
- Explore several websites in a browser.
- Identify the address bar, tabs, refresh button, and page content.
- Practical: compare two websites and identify their main sections.

### Day 2 — Files, folders, and VS Code
- Learn files, folders, file extensions, and project organisation.
- Open VS Code and create a course project folder.
- Practical: create a folder named `my-first-website` and an `index.html` file.

### Day 3 — Your first HTML page
- Learn what HTML does.
- Understand tags, elements, opening tags, closing tags, and attributes.
- Create a basic HTML document with a title, heading, and paragraph.

Starter example:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My First Website</title>
</head>
<body>
  <h1>Hello, World!</h1>
  <p>I am learning web development.</p>
</body>
</html>
```

### Day 4 — Preview your webpage
- Open the page in Chrome.
- Use Live Server if installed.
- Change text, save the file, and observe the browser.
- Practical: add a second heading and paragraph.

### Day 5 — Review and mini project
- Review browser, files, folders, HTML, and previewing.
- Build a simple personal webpage with your name, introduction, and interests.
- Explain the role of the HTML file.

## Practical exercises

1. Create a correctly named project folder.
2. Create an HTML file.
3. Add a page title, one main heading, and three paragraphs.
4. Open the page in a browser.
5. Change the content and refresh or use Live Server.

## Homework

Create a simple introduction page. Include your name or a fictional name, a short introduction, three interests, and a page title.

## Quick review

1. What is a browser?
2. What does HTML do?
3. What is a file extension?
4. Why do we use the `title` element?
5. What is the purpose of saving a file?

## Expected result

Every student can create, save, open, and edit a basic webpage.
