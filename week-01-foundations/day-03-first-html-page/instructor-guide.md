# Day 3 Instructor Guide — Your First HTML Page

## Teaching purpose

Students have created a project folder and an empty `index.html` file. Today they write their first HTML document. Keep the pace slow and explain the purpose of each section.

## Preparation checklist

- [ ] Check that each computer can open VS Code.
- [ ] Prepare the complete starter HTML example.
- [ ] Test the example in a browser.
- [ ] Open the HTML structure and element diagrams.
- [ ] Check that the projector is readable.
- [ ] Prepare a backup copy of the starter file.

## Two-hour lesson plan

### 1. Explain HTML — 20 minutes

Explain that HTML structures webpage content. Compare HTML, CSS, and JavaScript at a very high level.

Introduce tags and elements. Use the element-parts diagram to identify the opening tag, content, and closing tag.

Show the HTML document structure diagram. Explain the difference between head and body.

### 2. Quick review — 4 minutes

Ask:

1. What is the name of the file created yesterday?
2. What is a file extension?
3. Which VS Code panel shows project files?
4. Where is the project folder saved?

### 3. Instructor demonstration — 30 minutes

**A. Open the project (4 minutes)**

Open the `my-first-website` folder in VS Code and select `index.html`.

**B. Type the document structure (12 minutes)**

Type the example from the lecture notes. Pause after each section and explain its purpose. Avoid typing too quickly.

**C. Explain tags and elements (6 minutes)**

Highlight `<h1>`, `</h1>`, `<p>`, and `</p>`. Point out the opening tag, content, and closing tag.

**D. Change the content (4 minutes)**

Change the title, heading, and paragraph. Save the file.

**E. Preview briefly (4 minutes)**

Open the file in a browser using the method available in the classroom. Explain that Day 4 will focus on previewing and Live Server.

### 4. Student practical work — 62 minutes

- Enter the basic document: 20 minutes
- Change the title and heading: 10 minutes
- Add a paragraph about learning web development: 10 minutes
- Check the head and body sections: 10 minutes
- Rebuild the page with less help: 8 minutes
- Pair-check the result: 4 minutes

Help students with spelling and missing brackets. Encourage them to compare their work with the example rather than copying without understanding.

### 5. Practical review — 4 minutes

Ask students to show their saved `index.html`. Ask them to point out the title, body, heading, and paragraph.

## Common problems

| Problem | Instructor response |
|---|---|
| Missing angle bracket | Ask the student to compare the tag with the example |
| Missing closing tag | Find the opening tag and check for its matching closing tag |
| Content placed in head | Move visible content into body |
| Title appears in tab, not page | Explain that title and h1 have different purposes |
| File not saved | Use Save and check the editor tab for an unsaved marker |

## End-of-class checklist

- [ ] Students can explain the purpose of HTML.
- [ ] Students can identify an opening and closing tag.
- [ ] Students have a basic HTML document.
- [ ] Students have changed the title and page content.
- [ ] Every student has saved `index.html`.

## Teaching reminder

Do not introduce CSS, JavaScript, forms, or many new HTML tags today. A correct first document is the goal.
