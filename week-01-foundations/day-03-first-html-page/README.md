# Day 3 — Your First HTML Document

**Week:** 1 of 8 · **Session:** 2 hours · **Level:** Absolute beginner

## Lesson goal

Understand what HTML does and create a valid first HTML document with a page title, heading, and paragraph.

## Learning outcomes

By the end of this lesson, students can:

1. Explain that HTML gives webpage content its structure.
2. Recognise an HTML tag and an HTML element.
3. Identify opening and closing tags.
4. Explain the purpose of the `head` and `body` sections.
5. Create and save a basic HTML document named `index.html`.
