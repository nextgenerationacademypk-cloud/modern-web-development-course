## Activity 2 — Create your HTML document

1. Open VS Code.
2. Open your `my-first-website` folder.
3. Open `index.html`.
4. Type this complete document:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My First Website</title>
</head>
<body>
  <h1>Hello, World!</h1>
  <p>I am learning web development.</p>
</body>
</html>
```

5. Save the file.
