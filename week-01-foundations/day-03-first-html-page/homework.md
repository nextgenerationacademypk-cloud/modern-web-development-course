# Day 3 Homework — Create a Welcome Page

## Task

Open your `my-first-website/index.html` file and make a simple welcome page.

Your page must include:

1. A correct HTML document structure.
2. A meaningful page title.
3. One main heading.
4. Two paragraphs.
5. Correct opening and closing tags where required.

## Suggested content

- Welcome visitors to your first website.
- Write why you are learning web development.
- Write one thing you hope to build.

Use your own words. You may use a fictional name if you prefer.

## Check your work

- [ ] The file is named `index.html`.
- [ ] The title is inside the head.
- [ ] Visible content is inside the body.
- [ ] I used one main heading.
- [ ] I used two paragraphs.
- [ ] I saved my changes.

Bring your file to the next class. We will practise previewing webpages in a browser.
