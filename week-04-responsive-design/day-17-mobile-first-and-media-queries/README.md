# Day 17 — Mobile-First CSS and Media Queries

## Lesson goal
Build a simple layout for a narrow screen first, then improve it for wider screens with media queries.

## Learning outcomes
- Explain the mobile-first approach.
- Write a basic `@media (min-width: ...)` rule.
- Understand what a breakpoint does.
- Change a one-column layout into two columns at a suitable width.
- Test the result at multiple viewport widths.

## Class plan (120 minutes)
20 min explanation · 4 min theory review · 30 min demo · 62 min practical work · 4 min review.

## Required result
A mobile-first page with one column on a narrow screen and two columns on a wider screen.

## Learning resources
**Read:** [MDN: Media query fundamentals](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Media_queries) and [MDN: Responsive design](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design).

**Watch:** [Dave Gray: CSS Media Queries and Responsive Web Design for Beginners](https://www.youtube.com/watch?v=1p5q4r9r8s8) — if the video link is unavailable, use the MDN reading as the required resource; video is optional.

**Practise:** Change the example viewport width and observe when the layout changes.

## Homework
Create a mobile-first card layout with three cards. Keep one column by default and add a two-column layout at a wider viewport. Test and record the width where your layout changes.

## Quick check
1. What does mobile-first mean?
2. What is a breakpoint?
3. What does `@media` do?
4. Why do we often use `min-width` in mobile-first CSS?
5. Should every design use the same breakpoint? Explain.

## Completion check
Student can explain and demonstrate one media query.
