# Day 17 Homework — Mobile-First Card Layout

## Task
Create a page with three cards for a fictional academy, shop, or service.

Requirements:
1. Use one column as the default layout.
2. Add a media query that changes to two columns on a wider screen.
3. Use a gap between cards.
4. Add the viewport meta tag.
5. Test at 375px, 768px, and 1280px.

## Submit
- HTML and CSS files.
- A short note naming your breakpoint and explaining why you chose it.
- Screenshots at two different widths, if available.

## Optional challenge
Add a third column at a wider viewport.

## Reminder
Do not copy a breakpoint without testing. Choose a width that makes your own card content comfortable to read.
