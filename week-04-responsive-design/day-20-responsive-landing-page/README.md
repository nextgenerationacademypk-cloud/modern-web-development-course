# Day 20 — Responsive Landing Page Project

## Lesson goal
Combine mobile-first CSS, media queries, Flexbox, and Grid to build and test a complete responsive landing page.

## Learning outcomes
- Plan a simple page with a header, hero, feature cards, and footer.
- Use a flexible container and responsive navigation.
- Combine Flexbox and Grid where appropriate.
- Test at phone, tablet, and desktop widths.
- Find and fix horizontal overflow and readability issues.
- Explain the responsive choices in the project.

## Class plan (120 minutes)
20 min project briefing and design review · 4 min theory review · 30 min instructor build/demo · 62 min student project work · 4 min review.

## Project requirements
Build a one-page landing page for a fictional academy, shop, or service. Include:
- Header and navigation links.
- Hero section with heading, short paragraph, and call-to-action link.
- At least three feature or course cards.
- Footer.
- Viewport meta tag.
- Mobile-first CSS, at least one media query, and Flexbox or Grid.
- Images (optional) with alt text and responsive sizing if used.

## Learning resources
**Read:** [MDN: Responsive design](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design), [MDN: Media queries](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Media_queries), and [Chrome DevTools: Device Mode](https://developer.chrome.com/docs/devtools/device-mode/).

**Watch:** [freeCodeCamp: Introduction to Responsive Web Design](https://www.youtube.com/watch?v=srvUrASNj0s) — optional reference; students should focus on the concepts practised in class.

**Practise:** Use Chrome DevTools to test the finished page at 375px, 768px, and 1280px.

## Homework
Finish the landing page, test three viewport widths, and submit HTML/CSS plus a short testing note.

## Quick check
1. What is the mobile-first approach?
2. Why do we add a breakpoint?
3. When might you use Flexbox?
4. When might you use Grid?
5. How do you check for horizontal overflow?

## Completion check
Page has the required sections, remains readable at three widths, and has no unintended horizontal scrolling.
