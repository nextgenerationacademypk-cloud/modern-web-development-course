# Day 19 — CSS Grid and Responsive Images

## Lesson goal
Create a simple responsive grid and make images fit their containers without distortion.

## Learning outcomes
- Explain when CSS Grid is useful.
- Use `display: grid`, `gap`, and `grid-template-columns`.
- Understand the beginner-friendly use of `repeat()`, `minmax()`, and `auto-fit`.
- Make images responsive with `max-width: 100%` and `height: auto`.
- Test a grid at different viewport widths.

## Class plan (120 minutes)
20 min explanation · 4 min theory review · 30 min instructor demo · 62 min student practice · 4 min review.

## Required result
A responsive gallery or course-card grid and images that do not overflow their containers.

## Learning resources
**Read:** [MDN: Basic concepts of Grid Layout](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_grid_layout/Basic_concepts_of_grid_layout), [MDN: Responsive design](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design), and [MDN: Responsive images](https://developer.mozilla.org/en-US/docs/Web/HTML/Guides/Responsive_images).

**Watch:** [freeCodeCamp: Introduction to Responsive Web Design](https://www.youtube.com/watch?v=srvUrASNj0s) — optional; focus on the flexible images and layout sections.

**Practise:** Change the available width of today's grid and watch the columns adjust.

## Homework
Build a responsive image or course gallery using CSS Grid. Make each image fit its card and preserve its proportions.

## Quick check
1. What does `display: grid` do?
2. What does `gap` control?
3. What does `minmax(220px, 1fr)` mean in a grid track?
4. What does `auto-fit` help the browser do?
5. Why use `height: auto` with responsive images?

## Completion check
Student shows a grid that adapts to at least two widths and an image that does not overflow.
