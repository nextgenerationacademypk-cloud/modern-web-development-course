# Day 19 Homework — Responsive Gallery

## Task
Build a gallery for a fictional academy, library, or local service.

Requirements:
- At least three cards.
- CSS Grid for the card layout.
- A visible gap between cards.
- Images with useful alt text.
- Responsive image CSS: `max-width: 100%; height: auto;`.
- Layout tested at 375px, 768px, and 1280px.

## Submit
HTML and CSS files, plus a short note explaining how the grid changes at different widths.

## Optional challenge
Use `repeat(auto-fit, minmax(220px, 1fr))` and compare it with a media-query layout.
