# Day 16 Homework — Responsive Website Observation

## Task
Choose one familiar website (for example, a school, news, shop, or sports website). Open it on a computer and, if possible, on a phone. You may also use Chrome DevTools to change the viewport width.

## Answer these questions
1. What does the website show at the top of the page?
2. What changes when the screen becomes narrow?
3. Do the navigation links stay on one line, wrap, or become a menu?
4. Do images fit inside the content area?
5. Can you find any horizontal scrolling or text that is too small?

## Submit
- Website name (no account details).
- Three observations.
- One responsive problem you noticed, or write "I did not notice one".
- One idea to improve the page.

## Optional challenge
Create a simple HTML page with a container that uses `width: 90%` and `max-width: 1000px`. Test it at three widths.

## Safety
Do not submit passwords, private messages, personal account information, or screenshots containing private data.
