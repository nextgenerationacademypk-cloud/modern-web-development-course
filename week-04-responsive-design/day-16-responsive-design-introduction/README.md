# Day 16 — Responsive Design: The Big Picture

## Lesson goal
Understand why websites must adapt to different screen sizes and inspect a page at phone, tablet, and desktop widths.

## Learning outcomes
By the end of class, students can:
- Explain responsive web design in simple words.
- Identify common problems caused by fixed-width layouts.
- Explain viewport width and the viewport meta tag.
- Use Chrome DevTools device mode to inspect a page.
- Find horizontal overflow and readability problems.

## Prerequisites
Week 3 CSS foundations, the box model, and basic Flexbox.

## Class plan (120 minutes)
- 20 min: explanation — devices, viewport, fixed vs flexible layouts.
- 4 min: theory review.
- 30 min: instructor demo — inspect a page at different widths.
- 62 min: student practical exercises.
- 4 min: practical review.

## Required practical result
A simple page that can be inspected at three viewport widths, with a short list of problems found and corrected.

**Practise**

## Homework
Inspect one familiar website at phone and desktop widths. Record three differences and identify one layout issue that responsive design should prevent.

## Quick check
1. What does responsive design mean?
2. What is a viewport?
3. Why can a fixed 1000px container cause trouble on a phone?
4. What does the viewport meta tag help the browser do?
5. Name one problem you can find using device mode.

## Completion check
Student can switch device widths in DevTools and describe at least two visible layout differences.
