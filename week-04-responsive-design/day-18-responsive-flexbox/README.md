# Day 18 — Responsive Flexbox

## Lesson goal
Use Flexbox wrapping, flexible sizing, gap, and alignment to create layouts that adapt to available space.

## Learning outcomes
- Review flex containers and flex items.
- Use `flex-wrap: wrap`.
- Use `gap` for consistent spacing.
- Use flexible item widths with `flex` and `min-width`.
- Build a header and card row that can wrap on smaller screens.

## Class plan (120 minutes)
20 min explanation · 4 min theory review · 30 min demo · 62 min practical work · 4 min review.

## Required result
A responsive row of cards and a simple navigation/header that does not overflow when the viewport narrows.

## Learning resources
**Read:** [MDN: Basic concepts of Flexbox](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_flexible_box_layout/Basic_concepts_of_flexbox) and [MDN: Flex wrapping](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_flexible_box_layout/Wrapping_flex_items).

**Watch:** [freeCodeCamp: Introduction to Responsive Web Design](https://www.youtube.com/watch?v=srvUrASNj0s) — optional, use the Flexbox refresher section around 47 minutes onward.

**Practise:** Change the browser width and observe how cards wrap.

## Homework
Build a responsive row of four course cards. Use Flexbox, wrapping, gap, and a sensible minimum card width.

## Quick check
1. Which property turns an element into a flex container?
2. What does `flex-wrap: wrap` do?
3. Why is `gap` useful?
4. What is the difference between a fixed width and a flexible basis?
5. How can Flexbox help prevent overflow?

## Completion check
Student demonstrates cards wrapping without horizontal scrolling.
