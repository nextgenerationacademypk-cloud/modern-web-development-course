# Day 18 Homework — Responsive Course Cards

## Task
Create a page with four cards describing fictional courses.

Requirements:
- A flex container with `display: flex`.
- `flex-wrap: wrap`.
- A visible `gap`.
- Flexible card sizing such as `flex: 1 1 220px`.
- A heading and short description in each card.
- No horizontal overflow at phone width.

## Submit
HTML and CSS files, plus a short explanation of how `flex-wrap` helps.

## Optional challenge
Add a wrapping navigation bar above the cards.
