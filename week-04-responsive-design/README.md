# Week 4 — Responsive Web Design

## Goal
Build websites that remain readable and usable on phones, tablets, and desktop screens. Students start with small-screen layouts and enhance them for wider screens.

## Prerequisites
- Week 2 HTML structure and semantic elements.
- Week 3 CSS selectors, box model, Flexbox basics.
- Students should be comfortable opening and editing HTML/CSS files in VS Code.

## Core concepts
- Responsive design and viewport width.
- The viewport meta tag.
- Flexible containers and responsive images.
- Mobile-first CSS.
- Media queries and content-driven breakpoints.
- Flexbox wrapping and flexible sizing.
- CSS Grid, `repeat()`, `minmax()`, and `auto-fit`.
- Testing layouts with Chrome DevTools device mode.

## Practical project
Build a one-page landing page for a fictional academy, shop, or service. Include a header/navigation, hero section, at least three feature cards, and a footer. Use mobile-first CSS, at least one media query, and Flexbox or Grid. Test at 375px, 768px, and 1280px.

No JavaScript, Tailwind, or external CSS framework is required in Week 4. The goal is to strengthen foundational CSS responsive skills before the introductory Tailwind lesson in Week 7.

## Teaching guidance
Keep the examples small and let students resize the browser frequently. Do not ask beginners to memorize device-specific breakpoints. Add a breakpoint when the content needs a layout change. Avoid hamburger-menu JavaScript and advanced image loading features in this week.

## Weekly completion check
A student completes Week 4 when they can explain mobile-first design, write a basic media query, use Flexbox/Grid appropriately, make images responsive, and demonstrate a landing page that remains usable at phone, tablet, and desktop widths.
